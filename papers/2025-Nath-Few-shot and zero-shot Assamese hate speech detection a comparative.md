## Abstract

Benchmarks GPT-4, GPT-3.5, Mistral-7B alongside IndicBERT and mBERT for Assamese hate speech detection. GPT-4 achieves macro-F1 0.870 in few-shot (k=5), significantly outperforming fine-tuned mBERT (0.72). Uses extended Assamese dataset with code-mixed examples.

## Data Description

An extended Assamese hate speech dataset augmenting an existing Kaggle corpus with code-mixed and Romanized examples, used for systematic few-shot and zero-shot LLM benchmarking. No standalone public release URL identified in the paper.
