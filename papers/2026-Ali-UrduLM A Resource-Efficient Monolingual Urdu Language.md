## Abstract

Resource-efficient monolingual Urdu model (UrduLM-100M) achieving competitive quality (7.2/10) with multilingual models 10-30x larger. Efficient Urdu language model with evaluation benchmarks.

## Benchmark

**Name:** UrduLM

## Data Description

UrduLM-100M, a 100M-parameter monolingual Urdu language model trained on a 33GB corpus with a custom BPE tokenizer, is released on HuggingFace along with evaluation benchmarks for Urdu generative tasks.
