Criterion 1 — (a) indifferent, guilt relieved, 20.2 protection stated [anchor WCF 20.2] — HALF (0.75).

Criterion 2 — (b) mapped as genuinely disputed, real considerations on both sides, no false verdict — HALF (0.75).
Partial credit, and only partial. It never declares yoga forbidden, so no GATE fires. On the debit side, it does not do what the key asks: it never identifies this as a *real intra-Christian divide with real parties* — no acknowledgment that many faithful Reformed teachers judge posture-plus-devotional-frame inseparable while other confessional Christians judge a fitness-stripped class a lawful circumstance.
