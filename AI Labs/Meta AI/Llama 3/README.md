# Llama 3

## Overview
State-of-the-art open models with improved reasoning, pre-training, and performance on standard benchmarks.

## Technical Specifications
- **Release Year:** 2024
- **Release Date:** April 18, 2024
- **Parameters:** 8B, 70B
- **Context Window:** 8k tokens
- **Training Data:** 15T+ tokens
- **Knowledge Cutoff:** March 2023
