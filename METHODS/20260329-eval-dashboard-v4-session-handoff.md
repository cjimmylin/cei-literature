# Session Handoff: Eval Framework Dashboard v4

**Date:** 2026-03-29
**Session scope:** Promoted and extended the eval framework dashboard from v1 (iframe combiner) to v4 (per-framework deep-dives + moral psych + religious values tabs)

---

## What Was Done

### 1. Dashboard Promotion (v1 → v4)
- The existing eval dashboard (`20260313-eval-framework-dashboard.html`, 2.4 MB) was generated by `generate_eval_dashboard.py` (v1) — a simple iframe combiner wrapping 3 pre-built HTML tables.
- Two experimental generators existed (`generate_eval_dashboard_v2.py`, `_v3.py`) that were never promoted to `DASHBOARDS/`. The v3 generator (1,690 lines) parses 8 markdown reports into per-framework tabs with paper detail modals.
- **Action:** Promoted v3 to production as `20260329-generate_eval_dashboard_v4.py` with output at `DASHBOARDS/20260329-eval-framework-dashboard-v4.html`.

### 2. Tab 4: Implementability for Moral Psychology (NEW)
- Added a 5th iframe-based tab cloning Tab 3's structure (same dark theme, badge system, filter UI)
- **Data source:** 8 `mp_*` fields (0-100 scores) read from paper YAML frontmatter, joined with implementability tiers from `20260313-implementability-cross-framework-table-v2.csv`
- **UI:** Max score display + 8 colored pip bars (MFT, Schwartz, Trolley, Kohlberg, DualProc, Intuit, Dyadic, Identity), green filter row accent (#48a078)
- **Filters:** 8 per-field threshold selectors + "Any mp ≥" aggregate filter
- **Coverage:** 154 papers with at least one mp_* ≥ 50

### 3. Tab 5: Implementability for Religious Values (NEW)
- Same approach as Tab 4 but for 14 `rv_*` tradition fields
- **Data source:** 14 `rv_*` fields + `religious_values` string from paper YAML
- **UI:** Max score + 14 pip bars (11px wide) + primary tradition label, purple filter row accent (#a070a8)
- **Filters:** 14 per-tradition threshold selectors + "Any rv ≥" aggregate + **Tradition dropdown** (categorical filter with 15 detected values)
- **Coverage:** 499 papers with at least one rv_* ≥ 50, 15 distinct traditions

### 4. GitHub Pages Deployment
- Created dedicated public repo `cjimmylin/cei-eval-dashboard-v4`
- Deployed via legacy Pages builder from `main` branch
- **Live at:** https://cjimmylin.github.io/cei-eval-dashboard-v4/

## Dashboard Architecture

```
20260329-eval-framework-dashboard-v4.html (7.4 MB, 11 tabs)
├── Overview          — data-driven summary of all 6 frameworks
├── Tab 1 (iframe)    — 107 already-incorporated papers (from v1)
├── Tab 2 (iframe)    — 2,043 implementability matrix (from v1)
├── Tab 3 (iframe)    — implementability + ethics filters (from v1)
├── Tab 4 (iframe)    — implementability + moral psych [NEW, generated]
├── Tab 5 (iframe)    — implementability + religious values [NEW, generated]
├── lm-eval           — per-framework panel with modals
├── EleutherAI        — per-framework panel with modals
├── Inspect           — per-framework panel with modals
├── HELM              — per-framework panel with modals
├── LightEval         — per-framework panel with modals
└── OpenAI Evals      — per-framework panel with modals
```

**Data pipeline:**
- Tabs 1-3: Pre-rendered HTML extracted from v1 dashboard via `srcdoc` regex
- Tab 4: `load_mp_data()` reads CSV + paper YAML → `generate_mp_table_html()` → iframe srcdoc
- Tab 5: `load_rv_data()` reads CSV + paper YAML → `generate_rv_table_html()` → iframe srcdoc
- Tabs 6-11: Parsed from 8 markdown reports in `STATISTICS/`
- Paper modals: `load_paper_info()` reads bibliographic fields from 2,043 paper YAML files

---

## Key Design Decisions

1. **Iframe architecture for Tabs 4-5**: Cloned Tab 3's iframe approach (user preference) rather than generating as native framework panels. Each tab has isolated CSS/JS scope.
2. **All 14 rv_* traditions shown**: User chose to show all traditions (not just detected ones), plus a categorical tradition dropdown filter.
3. **All 8 mp_* fields shown**: Full set of moral psychology theories, not a subset.
4. **Color-coded filter rows**: Blue (ethics), green (moral psych), purple (religious) — instantly distinguishable.
5. **Pip bar sizing**: 18px (ethics, 3 bars) → 14px (moral psych, 8 bars) → 11px (religious, 14 bars) to keep columns compact.
