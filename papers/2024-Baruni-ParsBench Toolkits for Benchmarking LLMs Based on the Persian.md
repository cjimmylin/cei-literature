## Abstract

First Persian LLM leaderboard providing toolkits for benchmarking across various Persian language tasks. Open-source framework with customizable API for evaluation.

## Data Description

ParsBench provides benchmarking toolkits and two new Persian-language evaluation datasets (elementary school math and 7th/10th grade entrance exams) for assessing LLM performance across diverse Persian NLP tasks including sentiment analysis, QA, NLI, and translation.
