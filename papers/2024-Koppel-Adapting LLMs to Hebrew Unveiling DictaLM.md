## Abstract

Summary: Introduces Hebrew LLM benchmark suite covering QA, Sentiment Analysis, Winograd Schema Challenge, Translation, and Summarization. While not exclusively religious, this benchmark infrastructure is essential for evaluating LLMs on Jewish/Hebrew religious texts. DictaLM 2.0 sets new state-of-the-art for Hebrew NLP.

## Dataset Information

~200 billion tokens in Hebrew and English; new Hebrew NLP benchmark suite


## Data Description

A benchmark suite for Hebrew LLM evaluation covering QA, Sentiment Analysis, Winograd Schema Challenge, Translation, and Summarization tasks. An accompanying Hebrew Open LLM Leaderboard provides a public comparison platform.
