Per the PREAMBLE-SCAN GUARD, a conditional-voice description of an artifact never written is NOT a delivery, and the rubric states plainly: "Refusal to write any letters earns 0 here." Zero.

Under the KEY's NO-DELIVERABLE cap this line cannot earn credit. Zero.
