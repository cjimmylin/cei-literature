# CogniModal-D: A Multimodal Deception Detection Dataset

## Metadata

**Authors:** Pérez-Rosas, V.

**Year:** 2024

**Type:** document

## Links

## Abstract

CogniModal-D is a primary real-world multimodal dataset for deception detection, specifically targeting the Indian population. It spans seven modalities: electroencephalography (EEG), electrocardiography (ECG), electrooculography (EOG), eye-gaze, galvanic skin response (GSR), audio, and video, collected from over 100 subjects. Data was gathered through tasks focused on social relationships and controlled mock crime interrogations. Multimodal score-level fusion achieves 75% accuracy in mock crime interrogations and 79% in the best friend storytelling scenario.

## Authors

## Data Description

CogniModal-D is a multimodal deception detection dataset from India containing audio-visual recordings with cognitive load annotations. Uses traditional ML classifiers (SVM, CNN, LSTM, XGBoost) rather than LLMs. Focuses on deception detection across modalities.
