## Abstract

Evaluates multimodal AI using Korean national education tests: KoEGED, KoMGED, KoHGED, KoCSAT. KoCSAT has 897 items across 41 subjects. Tests cultural knowledge embedded in Korean educational standards.

## Data Description

KoNET is a multimodal benchmark built from four Korean national educational tests (KoEGED, KoMGED, KoHGED, KoCSAT) comprising 2,377 questions with images. The code and dataset builder are fully open-sourced.
