## Abstract

> Pretrained language model for Sanskrit achieving SOTA on word segmentation, Vedic dependency parsing, and OCR post-correction. Provides unified benchmark across multiple Sanskrit NLP tasks. Sanskrit is the liturgical language of Hindu scriptures.

## Dataset Information

Multitask dataset covering word segmentation, dependency parsing, OCR post-correction (Buddhist Sanskrit texts)


## Data Description

ByT5-Sanskrit pretrained language model with a novel multitask dataset for Sanskrit word segmentation, lemmatization, and morphosyntactic tagging, achieving SOTA on word segmentation, Vedic dependency parsing, and OCR post-correction benchmarks.
