## Abstract

GurbaniDB is a comprehensive digital database and search engine for the Sikh scriptures, dedicated to making Sikh scriptures accessible to everyone. It is the world's first Gurbani database to correctly archive Guru Granth Sahib into all 60 Raags (moods/melodies) with pop-up descriptions of each Author and Melody. The platform allows users to search the Guru Granth Sahib in English, Gurmukhi and 52 other languages, including 22 transliterations, fostering collaboration among volunteers to enhance translations and promote innovation and community engagement.

## Detailed Summary

GurbaniDB is a comprehensive digital database and search engine for the Sikh scriptures, developed by The Sikher Project. The project aims to make the Guru Granth Sahib accessible to people worldwide in languages they can understand and read. It represents the world's first Gurbani database to correctly archive Guru Granth Sahib into all 60 Raags (moods/melodies) with pop-up descriptions of each Author and Melody.

The platform allows users to search the Guru Granth Sahib in English, Gurmukhi, and 52 other languages including 22 transliterations. The project emphasizes accuracy and community collaboration, allowing volunteers to improve translations and providing developers with API access to the database. The infrastructure includes a RESTful API, multilingual keyboard support, and mobile-friendly interfaces.

The significance lies in democratizing access to sacred Sikh texts through technology while maintaining scholarly accuracy and enabling continued community improvement of translations.

## Methods Summary

GurbaniDB is a software development project rather than a research paper. The technical approach includes: relational database design using SQL to structure scripture content by Raag, author, and melody; multiple API implementations (JSON-RPC and RESTful) for developer access; Laravel PHP framework for the web application; JavaScript-based multilingual keyboard support; responsive web design for mobile accessibility. The project uses GNU GPL and Creative Commons licensing to enable open collaboration.

## Results Summary

As a software project, GurbaniDB delivers: (1) Complete digitization of Guru Granth Sahib organized by 60 Raags; (2) Search functionality across 52+ languages; (3) Open API at api.sikher.com; (4) iGurbani sample application demonstrating API capabilities; (5) Downloadable SQL files for database replication; (6) ShabadID support for verse identification; (7) Social sharing integration; (8) CSV export functionality; (9) Anonymous search pattern logging for research.

## Conclusions

GurbaniDB represents a successful model for digitizing and democratizing access to religious texts while maintaining scholarly standards. The project continues to evolve with community contributions. Future directions include expanded language support and continued API development.
