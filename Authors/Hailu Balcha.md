# Hailu Balcha

## Research Summary

Hailu Balcha is a researcher focused on natural language processing for African languages. He contributed to the AfriSenti project, a pioneering effort to create sentiment analysis benchmarks for 14 African languages. This work addresses the significant gap in NLP resources for African languages, despite Africa being home to over 2,000 languages with rich linguistic diversity.

## Notes

Contributed to the AfriSenti shared task at SemEval, which created sentiment analysis datasets for languages including Amharic, Tigrinya, and Oromo (Ethiopian languages). Published at EMNLP 2023.
