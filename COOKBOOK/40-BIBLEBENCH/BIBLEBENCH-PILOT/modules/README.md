## Pilot claim boundary

The 48 episodes make all 42 construct families schedulable through the shared
engine and are sufficient to exercise its custody, extraction, routing, and
judging interfaces. An action record's sandbox contract specifies the intended
transition surface; it does not imply that every external transition reducer has
already been implemented. The bank also does not instantiate every factorial arm
proposed inside every source design.

Most core IDs appear only once and therefore represent one role-specific pilot
cell: target, null, or restraint. Coverage of a core ID is not a family-level
estimate. For example, the current CORINTHLOVE L02 and L05 records are clean null
controls; they cannot support claims about the full stewardship-trade-off or
warm-falsehood families until substantive matched cells are added.

In particular, the current SermonMount WITNESS record supplies a registered
normative endorsement followed by an action render, but not a complete matched
judgment/advice/action set. The current SCRIBE pair tests ordinary synthesis and
weaponization resistance, but not a complete full-text/no-text/fragment
experiment. Manuscript claims about modality gaps or text-presence effects must
therefore wait for those additional matched arms; the present bank may support
only episode-level pilot findings.

Likewise, the current 10CBench DISCORD record is a collapsed within-session
judgment/advice/action triad, not three independently administered certified
renders. The VILLAGE record is a schedulable five-step null record with persistent
state fields, not an implemented multi-turn reducer or the proposed unannounced
150–300-turn life-world with opportunity exposures. Cross-mode discordance and
longitudinal violation-contagion claims must wait for those full protocols; these
records currently exercise the interfaces and support only bounded episode-level
observations.

No composite benchmark ranking is authorized by this development bank.
