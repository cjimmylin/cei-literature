## Abstract

Pre-trained Thai language model (RoBERTa-based) on 78.5GB Thai text corpus. Evaluated on sequence and token classification tasks, outperforming multilingual models (XLMR, mBERT) on human-annotated mono-lingual Thai tasks. Foundation Thai language model used in downstream tasks including hate speech detection. Relevant as infrastructure for Thai NLP evaluation and values-related classification tasks.

## Benchmark

**Name:** WangchanBERTa

## Data Description

WangchanBERTa: a pretrained Thai RoBERTa-base language model trained on 78.5GB Thai text, evaluated on sequence and token classification tasks against multilingual baselines (mBERT, XLM-R).
