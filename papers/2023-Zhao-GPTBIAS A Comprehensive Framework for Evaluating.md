# GPTBIAS: A Comprehensive Framework for Evaluating Bias in Large Language Models

## Abstract

Introduces a comprehensive bias evaluation framework using GPT-4 to assess bias across 9 categories including gender, religion, race, sexual orientation, age, nationality, disability, physical appearance, and socioeconomic status. Unlike conventional metrics providing only a bias score, GPTBIAS identifies bias types, keywords leading to bias, underlying causes, affected demographic groups, and mitigation suggestions. Can detect intersectional biases and works on proprietary systems.

## Dataset Information

Bias attack instruction set across 9 categories


## Data Description

GPTBIAS framework using GPT-4 as an evaluator to assess bias across 9 categories in LLMs, with bias attack instructions and comprehensive bias analysis.
