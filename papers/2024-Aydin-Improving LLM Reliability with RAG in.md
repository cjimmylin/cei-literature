# Improving LLM Reliability with RAG in Religious Question-Answering: MufassirQAS

[[Ahmet Yusuf Alan]], [[Enis Karaarslan]], [[Omer Aydin]]

## Links

## Abstract

Develops a RAG-based system to enhance LLM accuracy for Islamic religious question-answering. Builds a vector database from Turkish translations and interpretations of Islamic texts. Provides source page numbers and referenced articles for credibility. Demonstrates superior performance over ChatGPT on sensitive religious questions. Addresses hallucination risks in religious content generation.

## Dataset Information

Vector database of fundamental Islamic texts (Turkish translations and interpretations)


## Data Description

MufassirQAS builds a RAG knowledge base from Turkish translations and interpretations of the Quran (Kuran Yolu), Kutub-i Sitte (six hadith collections), and Islamic Catechism (Islam Ilmihali). The system is evaluated against ChatGPT (GPT-3.5-Turbo) on sensitive religious questions.
