## Abstract

First sentiment analysis benchmark for Modern Hebrew based on 12,804 social media comments from Israel president's Facebook page. Token-based and morpheme-based settings. 89% accuracy baseline.

## Data Description

First sentiment analysis benchmark for Modern Hebrew comprising 12,804 social media comments from the Israeli president's Facebook page, annotated for sentiment with token-based and morpheme-based settings.
