## Abstract

Largest benchmark for evaluating LLMs on generation tasks across 29 Indic languages covering 13 scripts and 4 language families. Includes cross-lingual summarization, machine translation, and question answering. Significant performance gap compared to English. Covers all four Dravidian languages. Tests generation capabilities with multi-way parallel evaluation data. Performance gaps highlight cultural and linguistic challenges.

## Benchmark

**Name:** IndicGenBench

## Data Description

INDICGENBENCH: the largest generation benchmark for 29 Indic languages across 13 scripts and 4 language families, covering cross-lingual summarization, machine translation, and question answering tasks with human-curated multi-way parallel evaluation data.
