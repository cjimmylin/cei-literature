### Automation Script Template

Future sessions can use this template for batch DOI resolution:

```python
# Template for DOI-based PDF recovery
import requests

dois_to_check = [
    "10.1007/s00146-021-01325-7",  # Stenseke
    "10.1177/09697330241238332",   # Muyskens
    "10.1515/mopp-2021-0026",      # Eisikovits
    "10.1186/s12909-025-06801-y",  # Okamoto
    "10.1038/s41598-025-86193-7",  # Pipitone
]

for doi in dois_to_check:
    # Check Unpaywall for open access version
    url = f"https://api.unpaywall.org/v2/{doi}?email=your@email.com"
    response = requests.get(url)
    if response.ok:
        data = response.json()
        if data.get('is_oa'):
            print(f"✅ {doi}: Open access at {data.get('best_oa_location', {}).get('url')}")
        else:
            print(f"❌ {doi}: No open access found")
```
