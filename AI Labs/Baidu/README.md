# Baidu

## Overview
Baidu is a Chinese multinational technology company specialized in Internet-related services and AI. It is a pioneer in knowledge-enhanced AI with its ERNIE series.

## Location
- **Headquarters:** Beijing, China
- **Region:** East Asia

## Key Models
See the full list of models: [[models|Baidu Models]]

- **ERNIE 4.5**: Latest flagship native multimodal foundation model.
- **ERNIE X1**: Deep-thinking reasoning model for complex inference.
- **ERNIE 3.0 Titan**: Massive 260B parameter model family.

## Alignment & Ethics
Baidu focuses on knowledge-enhanced AI, integrating massive knowledge graphs with deep learning to improve model veracity and social awareness.
