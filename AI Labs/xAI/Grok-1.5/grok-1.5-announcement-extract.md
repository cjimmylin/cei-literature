**Source:** https://x.ai/news/grok-1.5

## Summary

xAI announced Grok-1.5, featuring improved reasoning capabilities and a significantly expanded context window of 128,000 tokens.

## Key Features

### Context Window
- **128K tokens** - Up to 16 times longer than Grok-1
- Enables processing substantially longer documents
- Increased memory capacity for complex tasks

### Benchmark Performance

#### Mathematics
- **MATH Benchmark:** 50.6%
  - Covers grade school to high school competition problems
  - Wide range of mathematical problem types

- **GSM8K Benchmark:** 90%
  - Grade school math problems
  - Strong performance on fundamental mathematics

#### Coding
- **HumanEval:** 74.1%
  - Evaluates code generation capabilities
  - Tests problem-solving abilities

## Technical Infrastructure

Grok-1.5 is built on a custom distributed training framework:
- **JAX** - Machine learning framework
- **Rust** - Systems programming language
- **Kubernetes** - Container orchestration

This training stack enables the team to:
- Prototype ideas rapidly
- Train new architectures at scale
- Minimize development effort

## Improvements Over Grok-1

1. **Context Length:** 128K tokens (vs 8,192 tokens in Grok-1)
2. **Reasoning:** Enhanced mathematical and logical reasoning
3. **Coding:** Improved code generation and problem-solving
4. **Memory:** 16x increase in information retention

## Availability

Released to early testers and xAI Premium+ subscribers on the X platform.
