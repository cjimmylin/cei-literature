# Ajay Sukumar

## Research Summary

Ajay Sukumar is a researcher working on robust evaluation methodologies for large language models. His work focuses on developing functional benchmarks that can more accurately assess the genuine reasoning capabilities of language models, as opposed to pattern matching on static test sets. He contributed to the development of MATH(), a functional variant of the MATH benchmark that helps identify the "reasoning gap" between static and dynamic test performance.
