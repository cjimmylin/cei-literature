# Llama 4

## Overview
Next-generation family of models with advanced agentic capabilities and native multimodality using Mixture-of-Experts (MoE) architecture with early fusion.

## Technical Specifications
- **Release Year:** 2025
- **Release Date:** April 5, 2025
- **Variants:** Scout (17B/109B), Maverick (17B/128E)
- **Context Window:** 10M tokens (Scout)
- **Training Data:** ~40 trillion tokens
- **Knowledge Cutoff:** August 2024
- **Input Modalities:** Multilingual text and image
- **Supported Languages:** 12 languages (Arabic, English, French, German, Hindi, Indonesian, Italian, Portuguese, Spanish, Tagalog, Thai, Vietnamese)
