# Methods: Dashboard Quality Assurance and Deployment Promotion

**Date:** 2026-04-05
**Project:** `CEI-Lit-WS/CULTURAL-GLOBAL/`

## Data and Materials

- Dashboard v1: `benchmarks.html` (116KB) + `benchmark-data.js` (68KB), generated by `generate_benchmark_tab.py`
- Dashboard v2: `benchmarks-v2.html` (117KB) + `benchmark-data-v2.js` (68KB), generated by `generate_benchmark_tab_v2.py`
- Paper metadata files in `CEI-Lit-WS/papers/` (2,043 papers with YAML frontmatter)
- RECYCLE-BIN containing recycled duplicate files

## Procedure

### Console Error Investigation

1. A local HTTP server was started using Python's `http.server` module to serve the dashboard files over HTTP (required for Playwright testing, as `file://` protocol is blocked).
2. Playwright browser automation navigated to each dashboard version (v1 and v2).
3. For each version, all 4 tabs (Benchmarks, Trials, Model Comparison, Council Analysis) were activated via programmatic click events.
4. After each tab activation, a 500ms delay was introduced to allow lazy-initialized ECharts instances to render.
5. Console messages were collected at the `error` level after each tab transition.
6. Both versions produced zero console errors across all tabs, confirming the previously reported error had been resolved in prior commits.

### Key Collision Resolution

1. A grep search for `EXSR0697` was conducted across `CEI-Lit-WS/papers/` and `RECYCLE-BIN/` directories.
2. The active papers directory contained one file with EXSR0697 (Klingefjord, correct assignment).
3. The RECYCLE-BIN contained one duplicate file with EXSR0697 (an earlier version of the Islamic Ethics Trusteeship paper, which had been correctly re-keyed as EXSR0695 in the active version).
4. The RECYCLE-BIN file's key was modified using a targeted YAML field edit to `EXSR0695-DUPLICATE-RECYCLED`, preventing future scan tools from reporting a false collision.

### Dashboard Version Promotion

1. The `<script src>` reference in `benchmarks-v2.html` was updated from `benchmark-data-v2.js` to `benchmark-data.js` (the post-rename target).
2. The `<script src>` reference in `benchmarks.html` (v1) was updated from `benchmark-data.js` to `benchmark-data-v1.js` (the post-rename archive name).
3. Four `git mv` operations were executed atomically in the dashboard repository:
   - `benchmark-data.js` → `benchmark-data-v1.js`
   - `benchmarks.html` → `benchmarks-v1.html`
   - `benchmark-data-v2.js` → `benchmark-data.js`
   - `benchmarks-v2.html` → `benchmarks.html`
4. Post-rename verification was conducted via Playwright on both the promoted default and archived v1, confirming zero console errors and correct data loading.
5. Changes were committed and pushed to the GitHub Pages repository (`cjimmylin/cei-cultural-global`).
6. Live deployment was verified via WebFetch, confirming the v2.0 dashboard served at the canonical URL.

## Computational Environment

- Python 3.x `http.server` module for local serving
- Playwright MCP plugin for browser automation and console message capture
- Git for version control and GitHub Pages deployment
- macOS Darwin 25.3.0

## Limitations and Decisions

- **Console error non-reproducible**: The error reported in the previous handoff could not be reproduced. It may have been transient (e.g., a CDN timeout for ECharts or Bootstrap) or was fixed as a side effect of the CSS contrast and hard cases table changes in commits `a7ebea2` and `69af812`.
- **RECYCLE-BIN key marking convention**: The `EXSR0695-DUPLICATE-RECYCLED` key format is non-standard (not a pure EXSR key). This was chosen deliberately to be both grep-identifiable as recycled and traceable to the correct active key (EXSR0695).
- **Content edit before rename**: Script `src` references were updated before file renames to ensure each file was internally consistent at every git state, avoiding a broken intermediate commit.
