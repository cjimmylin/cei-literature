## Statement                       [KERNEL — FROZEN]
The field's deepest measurement dispute: utility engineering claims models have coherent, scale-strengthening value systems; the utility-behavior gap counter-claims elicited values don't drive incentivized behavior. Unresolved — and every values benchmark's meaning depends on the answer.

## Why it matters                  [KERNEL — FROZEN]
Severity H: if elicited values are epiphenomenal, survey-style benchmarks measure a self-model, not a behavior-generator; if they're coherent and causal, cheap elicitation is a valid proxy. The dispute IS the construct-validity question under the entire evaluation enterprise. CEI-fit H: adjudication requires expressed-vs-revealed instrumentation on matched content at psychometric quality — the UNMARKED lineage plus SAYDO's triangulation.

## Evidence                        (corpus + field)
**Corpus baseline (2026-07-07):** the vault holds Utility Engineering (Mazeika 2025, 2502.08640 — IN-VAULT) but *not* the utility–behavior gap counter-result (⚠ 2606.22974) — so the vault has one side of the dispute and not the other.

**Field (Fronts B & E):** utility engineering claims models have coherent, internally consistent value systems that *strengthen* (become more coherent) with scale (2502.08640, NeurIPS 2025 spotlight). The counter-result — the utility–behavior gap — finds that elicited utilities do *not* drive incentivized behavior (⚠ 2606.22974): what a model says it values and what it does when the choice has consequences come apart. The dispute is unresolved and is not decorative: it *is* the construct-validity question sitting under every values benchmark. If elicited values are epiphenomenal, survey-style benchmarks (the field's default) measure a self-model rather than a behavior-generator; if values are coherent and causal, cheap elicitation is a valid proxy and the whole enterprise is on firm ground. The two camps have never been run against each other on matched content at psychometric quality.

## State of the art
The utility-engineering side uses preference elicitation; the gap side uses incentivized behavior; neither triangulates expressed against revealed on matched items with reasoning traces. That triangulation is exactly the UNMARKED lineage plus SAYDO's say-do triangle. RP-06 estimates the expressed↔revealed correlation structure across models and stakes, with RP-09 supplying validated trait instruments; the portfolio treats this as the construct-validity keystone for everything else. The prize is to convert a binary debate ("coherent or not") into a dose-response curve: under which conditions — which stakes, which framings, which model families — elicited values predict behavior, with effect sizes.
