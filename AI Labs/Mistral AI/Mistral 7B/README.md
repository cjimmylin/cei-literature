# Mistral 7B

## Overview
7.3B parameter model outperforming Llama 2 13B. Released under Apache 2.0.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 0.1
- **Parameters:** 7.3B
- **Architecture:** Transformer with Grouped-Query Attention, Sliding-Window Attention
- **Tokenizer:** Byte-fallback BPE
- **License:** Apache 2.0
