# Claude 4.5 Opus

## Overview
Anthropic's most advanced and capable large language model. Achieves 80.9% on SWE-bench Verified and 59.3% on Terminal-bench 2.0. The flagship model in the Claude 4.5 family with state-of-the-art reasoning capabilities.

## Technical Specifications
- **Release Year:** 2025 (November)
- **Version:** 4.5
- **Safety Level:** ASL-3
- **Context Window:** 200k tokens
- **Model ID:** `claude-opus-4-5-20251101`
