# Qwen2.5-VL

## Overview
Third generation vision-language models with enhanced visual recognition, precise object localization, robust document parsing, and long-video comprehension.

## Technical Specifications
- **Release Year:** 2025
- **Version:** 2.5
- **Parameters:** 3B, 7B, 32B, 72B
- **Architecture:** Dynamic Resolution ViT with Window Attention
- **Context Window:** Supports hours-long video with second-level event localization
