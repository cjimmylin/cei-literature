## Abstract

AI alignment considers how we can encode AI systems in a way that is compatible with human values. The normative side of this problem asks what moral values or principles, if any, we should encode in AI. To this end, we present a framework to consider the question at four levels: Individual, Organizational, National, and Global. We aim to illustrate how AI alignment is made up of value alignment problems at each of these levels, where values at each level affect the others and effects can ﬂow in either direction. We outline key questions and considerations of each level and demonstrate an application of this framework to the topic of AI content moderation.

## Data Description

This paper presents a conceptual framework for considering the AI alignment problem at four levels: Individual, Organizational, National, and Global. It does not create or evaluate any dataset or benchmark. The paper applies the framework to AI content moderation as a case study and includes an AI x-risk analysis template.
