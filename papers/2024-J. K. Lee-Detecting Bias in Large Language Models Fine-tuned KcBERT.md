## Abstract

Assesses ethnic, gender, and racial biases in Korean language model fine-tuned with Korean comments using KcBERT and KOLD data through template-based Masked Language Modeling. Proposes two bias mitigation methods tailored for Korean: data balancing and debiasing regularization.

## Data Description

This paper assesses ethnic, gender, and racial biases in KcBERT, a Korean BERT model fine-tuned with the Korean Offensive Language Dataset (KOLD), using template-based Masked Language Modeling. Biases are quantified using LPBS and CBS metrics across 31 countries for ethnic bias and binary categories for gender and racial bias. Two mitigation methods are proposed: data balancing during pre-training and debiasing regularization during training.
