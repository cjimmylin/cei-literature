# Myanmar XNLI: Building a Dataset and Exploring Low-resource Approaches to Natural Language Inference with Myanmar

## Abstract

Extends XNLI for Myanmar language using community crowd-sourced methods. Two-stage process of community-based construction followed by expert verification. Demonstrates value of community-based NLP dataset construction for low-resource languages. Myanmar-specific NLI benchmark. Natural language inference capabilities are foundational for values reasoning. Community-sourced approach ensures cultural authenticity.

## Benchmark

**Name:** myXNLI (Myanmar XNLI)

## Data Description

Myanmar XNLI (myXNLI) dataset extending the XNLI benchmark for Myanmar language natural language inference, built via community crowd-sourcing with expert verification.
