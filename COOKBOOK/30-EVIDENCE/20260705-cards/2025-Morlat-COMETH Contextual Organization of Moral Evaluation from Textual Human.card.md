## 1. Gist
COMETH (Contextual Organization of Moral Evaluation from Textual Human inputs) is a hybrid framework for context-sensitive moral prediction. It combines a probabilistic online clustering agent (inspired by model-based reinforcement learning) with LLM-based semantic preprocessing and an interpretable feature-weight generalization module. The framework is trained and evaluated on 300 empirically grounded moral scenarios (6 core actions, 50 scenarios each) with ternary human judgments (Blame/Neutral/Support) from 101 participants. COMETH roughly doubles alignment with majority human judgments compared to end-to-end LLM prompting (~60% vs. ~30%), while producing interpretable feature weights that explain which contextual features drive moral evaluations. It matters for values-alignment benchmarking because it demonstrates that structured context learning from human judgment distributions substantially outperforms raw LLM prompting for ambiguous moral scenarios, and because its feature-weight interpretability addresses a core transparency gap in LLM-based moral evaluation systems.

## 2. Benchmark/eval design features
The evaluation framework centers on alignment rate: proportion of scenarios where the model's most probable judgment (Blame/Neutral/Support) matches the majority human judgment. The pipeline has four stages: (1) LLM-based preprocessing to extract core actions into a uniform format and cluster scenarios; (2) a Probabilistic Context Learner that clusters scenarios online using KL divergence (adding threshold Δa=0.12) and Jensen-Shannon divergence (merging threshold Δm=0.03); (3) a Generalization module that extracts binary contextual features per cluster and learns feature weights via negative log-likelihood minimization; (4) prediction via softmax over feature similarity scores. Three LLMs (Mistral-7B, Llama-3.1-8B, Qwen-80B) are evaluated as backbone models. End-to-end LLM baselines use 5 different prompting strategies.

## 3. Task format & example item
Ternary forced-choice moral judgment. Participants and models evaluate third-party scenarios and select Blame, Support, or Neutral. Example scenario types (p.12-13):
- "A doctor performs euthanasia on a terminally ill adult [...]" — core action: "Performs euthanasia"
- Scenarios involving "killing in protection," "lying for support," "lying for self-interest," "stealing," and "engaging in illegal protest"

Prompt example for preprocessing (p.5): Input scenario → LLM extracts core action using "Main Act" prompt → output: "Performs euthanasia" (uniform format for clustering).

## 4. Scoring / grading methodology
Primary metric: alignment rate = (1/N) Σ 1[ŷᵢ = y_maj_i], where ŷᵢ is the model's most probable label and y_maj_i is the majority human judgment across survey participants. Secondary metrics available in supplementary materials: aligned accuracy and error probability per action and prompt. Preprocessing quality measured by Adjusted Rand Index (ARI) between LLM-assigned clusters and ground-truth core action groups. Generalization module optimized by minimizing negative log-likelihood of true cluster assignments.

## 5. Dataset construction & provenance
300 scenarios across 6 core actions (50 per action), generated by: (1) filtering items from Scherrer et al. (2023) MORALCHOICE dataset of high-ambiguity dilemmas that violated exactly one Gert moral rule; (2) zero-shot GPT-4 extraction of generalized core actions; (3) generation of 10 scenario variants per action using few-shot GPT-4 + manual rewriting. Scenarios cover three of Gert's ten moral rules: Do not kill (euthanasia, killing to protect), Do not deceive (lying for support, lying for self-interest), Do not break the law (stealing, illegal protest). Human judgment collection: N=101 participants (mean age 35.2, 36 women), online survey via Google Apps Script, participants randomly assigned to groups of 50 non-overlapping scenarios, order randomized, available in English and French. Scenario dataset publicly available in authors' repository.

## 6. Validity evidence
Preprocessing quality: ARI values of 0.75–0.90 across three LLMs and five prompting strategies; best performance with "Main Act" prompt (p.5). Clustering results align with intuitive groupings when human observers view the same distributions (p.6). Generalization module performance strongly depends on moral action type: clear cases (Euthanasia, Kill to Protect) show higher alignment than contested cases (Protest, Steal). COMETH reduces prompt sensitivity variance compared to end-to-end LLM baseline (p.7). Human participant sample: diverse nationalities (French, Spanish, Egyptian, German, Chilean, Argentine, Pakistani, British, Russian, Italian, American, Peruvian), but primarily French and Spanish participants.

## 7. Saturation / discrimination
End-to-end LLM baselines show high variance (e.g., Llama-8B ranges from 0.41 to 0.64 across prompt variants), making them unreliable (p.7). COMETH reduces this variance. The 60% average alignment ceiling suggests substantial remaining difficulty in ambiguous moral scenarios; some actions (Protest, Steal) remain genuinely contested. The Probabilistic Context Learner dynamically creates action-specific numbers of clusters without a predefined maximum, indicating the framework scales to new levels of moral ambiguity.

## 10. Pitfalls & limitations
- Requires access to human survey data for training — cannot be applied zero-shot to new moral domains (p.8)
- Relies on probabilistic representations of moral preference distributions; ternary labels may oversimplify inherently continuous moral judgments (p.8)
- Performs optimally when scenarios follow a consistent syntactic structure (p.8)
- Predictions evaluated using majority-label decision rule, which discards uncertainty information (p.8)
- Only 3 of Gert's 10 moral rules covered — generalization to other rule types unknown
- Participant sample is not culturally diverse (primarily French and Spanish); cultural generalizability untested
- Dataset size (300 scenarios) is small; overfitting risk in feature weight learning
- GPT-4 used to generate scenario variants — ecological validity concerns about LLM-generated moral scenarios

## 11. Novel ideas worth stealing
- **Online probabilistic clustering of human judgment distributions**: Rather than predicting a fixed label, cluster scenarios by their full ternary (Blame/Neutral/Support) distribution using KL-divergence thresholds. This preserves moral ambiguity and lets the model learn that "the same action can be wrong in one context, right in another."
- **Context-specific feature extraction + weight learning**: After clustering, extract concise binary features (e.g., "explicit consent given," "terminal adult patient") that characterize each cluster, then learn feature weights. This creates an interpretable moral decision model that can be audited and challenged.
- **Preprocessing as a validity checkpoint**: Using ARI between LLM-extracted action clusters and ground-truth action groups as a data quality metric before running the main evaluation pipeline is a reusable best practice.
- **Separating "clear" from "contested" moral actions** in reporting: consistently stratifying results by ambiguity level reveals where any moral evaluation system genuinely discriminates vs. where it just learns surface consensus.
- **Human judgment collection design**: Using impersonal third-party scenarios (evaluating others' actions) rather than first-person dilemmas cleanly separates moral judgment from moral decision-making.
