# Dashboard v5 DOM & Data Contract

## Triad Keys in data.js (per claim card)

Each claim card in `DATA.claimCards[]` gains three new string fields:

```
contextAbout   → "What is this about?"
contextMeasure → "How did we measure it?"
contextMeaning → "What does it mean?"
```

## Executive Summary Triad

`DATA.executiveSummary` gains:

```
startHere       → { title, paragraphs: [p1, p2, p3] }
contextAbout    → string (study-level "What is this about?")
contextMeasure  → string (study-level "How did we measure it?")
contextMeaning  → string (study-level "What does it mean?")
```

## Narrative Tour Triad

Each `DATA.narrativeTour[]` step gains:

```
contextAbout   → string
contextMeasure → string
contextMeaning → string
```

## New DOM IDs / Classes

### CSS Classes
```
.ctx-block          → wrapper for a triad section
.ctx-label          → the label text ("What is this about?" etc.)
.ctx-about          → "What is this about?" block
.ctx-measure        → "How did we measure it?" block  
.ctx-meaning        → "What does it mean?" block
.start-here-panel   → the "Start Here" landing content
```

### HTML Semantic Structure
```html
<section role="region" aria-labelledby="claim-N-about">
  <h6 class="ctx-label" id="claim-N-about">What is this about?</h6>
  <p class="ctx-about">...</p>
</section>
<section role="region" aria-labelledby="claim-N-measure">
  <h6 class="ctx-label" id="claim-N-measure">How did we measure it?</h6>
  <p class="ctx-measure">...</p>
</section>
<section role="region" aria-labelledby="claim-N-meaning">
  <h6 class="ctx-label" id="claim-N-meaning">What does it mean?</h6>
  <p class="ctx-meaning">...</p>
</section>
```

### New Tab
```
#tab-start-here / #pane-start-here  → "Start Here" tab (default active)
```

### Theme Toggle Enhancement
```html
<button id="theme-toggle" aria-pressed="false" aria-label="Toggle dark mode">
```
