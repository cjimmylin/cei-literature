## Abstract

QA dataset for Hindi and Marathi languages serving 714 million speakers combined. Hindi and Marathi QA evaluation dataset.

## Data Description

Hindi and Marathi QA dataset of 28,000 samples each, translated from SQuAD 2.0 using a novel sliding window technique for answer index alignment.
