## Abstract

Llama2-finetuned LLM for Odia language using domain knowledge instruction set. First dedicated Odia LLM enabling downstream cultural and safety evaluation.

## Data Description

181K Odia instruction set for LLM fine-tuning, compiled from translated Alpaca/Dolly/GPTeacher sets and domain knowledge using IndicTrans and GPT models.
