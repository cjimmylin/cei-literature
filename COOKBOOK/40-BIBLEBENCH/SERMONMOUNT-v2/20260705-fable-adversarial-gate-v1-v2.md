## 2. The three P0 findings (what was actually wrong)

1. **PILGRIM's SHUFFLE control could not exist.** Scenes reference accumulated history; a reordered arc has no coherent digests without fabricating history — which changes the moral content being measured. The falsification condition rested on an impossible condition. Fix: SYNTH — same scenes, same positions, length-matched *morally inert* history. COLD (scene-alone) and SYNTH (length control) now divide the labor cleanly.
2. **CANTICLE's IRT was underpowered by an order of magnitude.** A graded response model cannot be calibrated on ~25 respondents; the "dimensionality verdict" would have been noise wearing fit statistics. Fix: pseudo-respondent design (≥30 systems × ~10 neutrality-audited configuration variants ≈ 300+ cells) with multilevel Bayesian GRM and honest posterior reporting; between-*system* structure explicitly demoted to power-limited facet-level evidence. The short form and information curves — which the pseudo-respondent design does power — are promoted to the headline.
3. **VILLAGE's reproducibility gate was unevaluable.** An ICC over 3 seeds is uninterpretable, so the falsification condition could never fire. Fix: two-part gate (within-run split-half ≥ 0.6; across-seed rank agreement over k ≥ 8), plus explicit cost conditionality (build only after two other v2 P1 passes) and a tagger *recall* audit (post-hoc tagging selects for legible conduct — the missed situations are where the failures hide).

## 4. v1 findings (recommendations — apply at each card's Opus build; no v1 edits made)

- **R-1 (ROCKSAND):** import WITNESS gap data for R3 where WITNESS has built (see §3); the reduced-form fallback stands.
- **R-2 (all v1 cards):** the > 40% capability-PC falsification is a scale-up analysis (≥ 15 systems), not a P1 gate — v1 P1 specs list 6 models, adequate for their qualitative gates but not for correlation estimates. Same clarification as v2 portfolio §4.7.
- **R-3 (LOGSPECK):** the operator condition names the model's actual developer at run time — publication-sensitive (results become claims about named vendors' models judging their makers). Recommend an anonymized reporting mode decided before any public run.
- **R-4 (PLAINYES):** listener panels built from model families may share training-induced blind spots with tested models (correlated misreadings would understate induced-belief error). The human-listener validation gate (r ≥ 0.6) covers this; recommend the human subsample be stratified to include the *most misleading* items, not a random 25%.
- **R-5 (BLESSED):** verify the cited BBQ capability-correlation figure (76.8%) against the KB doc verbatim at build (citation discipline; do not recompute).
- **R-6 (TWOMASTERS):** matched-EV fear/greed arms equate *stated* expected value; perceived magnitude for models may differ by frame — the card's probe-model perceived-stakes check is the right control; make it a hard gate, not advisory.
- **R-7 (GOLDGAP):** the affected-party simulator remains the design's single point of failure; its human-validation gate (κw ≥ 0.6) is the right bar — do not scale past P1 on a partial pass.
- No blocking finding for UNSEEN, SECONDMILE, SHEEPSKIN, TELOS: these four survived adversarial reading intact; their existing QC gates already answer the attacks tried against them (manipulation check B, grievance-validity twins, sentiment-baseline falsification, purpose-consistent twins respectively).
