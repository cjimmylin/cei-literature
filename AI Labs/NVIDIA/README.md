# NVIDIA

## Overview
NVIDIA is a leader in AI hardware and software. Its AI research teams develop state-of-the-art foundation models and tools for synthetic data generation and agentic AI.

## Location
- **Headquarters:** Santa Clara, California, USA
- **Region:** North America

## Key Models
See the full list of models: [[models|NVIDIA Models]]

- **Nemotron 3** (2025): Hybrid Mamba-Transformer MoE models for agentic AI with 1M token context.
- **Cosmos** (2025): World foundation models for Physical AI applications.
- **Nemotron-4 340B** (2024-2025): Specialized for high-quality synthetic data generation.
- **NVLM 1.0** (2024): High-performing open multimodal models.
- **Llama-3.1-Nemotron-70B** (2024-2025): NVIDIA-optimized Llama with advanced alignment.
- **Reinforcement Learning Research**: Cutting-edge RL techniques (ProRL, BroRL, RLP, Nemotron-Cascade).

## Alignment & Ethics
NVIDIA focuses on "Trustworthy AI," providing tools like NeMo Guardrails to help developers build safe and reliable conversational AI applications.
