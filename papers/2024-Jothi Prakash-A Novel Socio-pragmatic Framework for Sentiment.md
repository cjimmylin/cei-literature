## Abstract

Socio-pragmatic framework for sentiment analysis in Dravidian code-switched texts using XLM-RoBERTa with socio-pragmatic insights. Achieved 72.3% accuracy, 72.5% F1-score on Dravidian Code-Mixed Dataset. Culturally grounded sentiment analysis for Dravidian languages. Socio-pragmatic approach captures cultural nuances in code-switched text.

## Benchmark

## Data Description

The Dravidian Code-Mixed Dataset used for training and evaluating the socio-pragmatic sentiment analysis framework for Dravidian code-switched texts.
