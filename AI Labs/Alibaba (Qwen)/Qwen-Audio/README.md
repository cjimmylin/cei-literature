# Qwen-Audio

## Overview
First generation audio-language model for universal audio understanding via unified large-scale audio-language pretraining.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 1.0
- **Architecture:** Audio encoder + Qwen LLM
- **Capabilities:** Speech recognition, audio analysis, multi-turn dialogue, 30+ audio tasks
