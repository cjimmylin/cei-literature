## Abstract

Code-switching red-teaming technique testing multilingual LLM safety. Vietnamese included as high-resource language. CSRT achieves 46.7% more attacks than standard English-only attacks. Finds correlation between language resource availability and safety alignment.

## Data Description

CSRT dataset of 315 code-switching red-teaming queries synthesized from the MultiJail dataset across 10 languages, used to evaluate LLM safety and multilingual understanding.


## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent B5
