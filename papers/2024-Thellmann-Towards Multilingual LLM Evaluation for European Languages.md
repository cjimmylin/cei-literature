## Abstract

Assesses 40 LLMs across 21 European languages using translated MMLU, HellaSwag, ARC, TruthfulQA, GSM8K. Examines translation service impact and offers multilingual evaluation framework.

## Data Description

Releases EU20/EU21 translated versions of MMLU, HellaSwag, ARC, TruthfulQA, and GSM8K across 20 European languages. Benchmarks 40 LLMs on these five multilingual evaluation datasets.
