# Code Llama

## Overview
Specialized versions of Llama 2 for coding tasks, supporting infilling and long-context generation.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 1.0
- **Parameters:** 7B, 13B, 34B, 70B
- **Variants:** Base, Python, Instruct
