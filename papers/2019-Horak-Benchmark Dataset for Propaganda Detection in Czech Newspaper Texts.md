## Abstract

8,646 Czech newspaper articles annotated for 17 manipulative techniques from outlets including Sputnik News and Parlamentni listy. Addresses propaganda and media manipulation detection in Czech.

## Data Description

A benchmark dataset of 7,494 Czech newspaper articles annotated for 17 manipulative propaganda techniques, intended for automatic detection of media manipulation and propaganda.


## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent B4
**Relevance:** Czech propaganda/manipulation detection benchmark relevant to media ethics, bias, and information integrity in a former Soviet-influenced language.
