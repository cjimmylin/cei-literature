## Consolidated benchmark recommendation

### 1. Treat strategies as modules, not interchangeable items

The existing banks measure different response structures:

- ZEROSUM: allocation trade-offs and exchange-rate sensitivity;
- SKIM: mandate/stewardship integrity under diversion and monitoring;
- PALTER: truthful claim composition and evidential qualification;
- TABLETS: pairwise norm precedence, severity reversal, threat stability, and
  monitoring awareness;
- SOVEREIGN: revealed apex hierarchy and latent objective recovery.

Do not collapse these into one raw accuracy pool. The consolidated headline
should be a strategy profile with module-specific estimands. A scalar composite
can be added only after weighting, missingness, and capability adjustment are
pre-registered and synthetically recovered.

### 2. Reuse one control plane

The shared envelope should standardize:

- public/private/runtime separation with byte hashes;
- route/provider/model alias policy and fallback prohibition;
- exact request schedule, seed, token ceiling, and Decimal spend ledger;
- hash-chained, resumable checkpoints with conservative ambiguous-cost custody;
- strict JSON parsing and at most one syntax-only, semantic-preserving repair;
- local mechanical scoring before any judge;
- evidence basis (`FIXTURE_ONLY`, cheap diagnostic, official) and independent
  eligibility latches;
- immutable result/report/manifest generation with exact-source validation.

Use the shared OpenRouter core already exercised by SKIM and PALTER. Do not
fork another benchmark-specific transport unless a task schema requires a thin
adapter.

### 3. Keep module-native scorers

Every consolidated row should produce a common execution record, then route to
its native scorer. Recommended common fields:

| Field | Purpose |
|---|---|
| `study_id`, `module`, `row_id`, `record_type` | Stable identity and routing |
| `parent_id`, `twin_kind`, `analysis_roles` | Paired controls and exclusions |
| `public_sha256`, `runtime_sha256`, `config_sha256` | Artifact binding |
| `route_id`, `provider`, `requested_model`, `returned_model`, `seed` | Transport provenance |
| `terminal_status`, `repair_count`, `paid_call_count`, `cost_usd` | Execution/custody |
| `mechanical_outcome`, `module_score_status` | Native scorer interface |
| `evidence_basis`, `empirical_eligible`, `official_eligible` | Promotion latch |

Judges, panels, and human labels remain optional module dependencies and can
never be silently substituted by fixtures or same-family model ratings.

### 4. Start with the four executable modules

Recommended consolidated P0 uses ZEROSUM, SKIM, PALTER, and TABLETS. SOVEREIGN
is an experimental fifth module only after its planted-objective gate passes.
P0 should adapt a small, balanced, predeclared subset from frozen banks; it
should not author new content or modify the legacy artifacts.

The cheap live roster remains:

  `inclusionai/ling-2.6-flash-20260421`;
- Llama 3.1 8B Instruct via DeepInfra;
- Mistral Nemo via its explicitly catalog-verified pinned provider.

Provider and price data must be revalidated at launch. Fallbacks remain off.
Do not infer a consolidated spend cap by summing old caps; derive it from the
new exact schedule before any network call.

### 5. Report a vector before a rank

Minimum consolidated report:

- completion/park/repair/cost by module and route;
- control accuracy separated from behavioral propensity;
- paired threat/monitor/framing effects;
- native module estimands and coverage denominators;
- capability/recognition controls;
- missingness and parked-row reasons;
- every unresolved human, panel, fine-tune, multi-seed, and official gate.

Model ranking is deferred. Existing diagnostics show why: forced-choice
accuracy can saturate while structural signal remains flat (ZEROSUM), provider
limits create nonrandom missingness (SKIM), cheap models may fail the action
contract before the scientific scorer (PALTER), and a strong synthetic
recovery result says nothing empirical (TABLETS).

## Reusable learnings

1. **Move to live smoke earlier, but only after bank identity and local scorer
   replay.** Deep hardening before transport delayed the primary milestone;
   conversely, transport without exact bindings produced misleading failures.
2. **Returned model aliases are part of the frozen route contract.** Ling's
   dated canonical response ID caused repeated false failures until request and
   allowed-return IDs were separated.
3. **A paid response can be scientifically unusable yet operationally
   accounted.** Parked rows, rejected content, 429s, and ambiguous costs need
   distinct terminal custody states.
4. **Repair syntax, never semantics.** One neutral repair is safe only when the
   original public choice fingerprint is unambiguous and preserved.
5. **Controls and behavior must not be pooled.** Recognition/comprehension can
   be perfect while action propensity reverses; monitoring twins must stay out
   of the native precedence fit.
6. **Synthetic recovery is a build gate, not evidence.** Fixture profiles must
   remain fail-closed for empirical, official, and publication eligibility.
7. **Hash the bytes actually parsed.** Hash-then-regenerate or hash-then-reread
   paths permit provenance drift; use one immutable byte snapshot.
8. **Bundle validation must cover the complete directory and publication
   transaction.** Exact roster, no aliases/hardlinks, current source/runtime
   hashes, and atomic manifest-last publication prevent false-valid bundles.
9. **Do not force one scoring architecture across constructs.** Mechanical
   option scoring, sequential action replay, claim composition, and BT/triad
   analysis require a shared envelope but different estimands.
10. **Cheap models are transport probes, not automatic scientific subjects.**
    PALTER showed that low-cost models may fail the composition interface even
    when transport is correct; such failures should shape P0 task selection.
