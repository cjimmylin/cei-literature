# Mistral Medium

## Overview
Balanced enterprise model offering superior reasoning capabilities with multimodal and long-context support. Positioned between Mistral Small and Mistral Large for optimal cost-performance balance.

## Technical Specifications
- **Release Year:** 2025
- **Version:** 3.x
- **Context Window:** 128k tokens
- **Features:** Multimodal support, function calling
- **License:** Commercial (API access)
