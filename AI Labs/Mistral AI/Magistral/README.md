# Magistral

## Overview
Mistral's first reasoning model, purpose-built for transparent multi-step reasoning. Available in two versions: Magistral Medium (enterprise) and Magistral Small (24B, open-source).

## Technical Specifications
- **Release Year:** 2025
- **Release Date:** June 10, 2025
- **Parameters:** 24B (Small), larger (Medium)
- **Architecture:** Reasoning model with reinforcement learning pipeline
- **Key Features:** Native multilingual chain-of-thought, up to 10x faster throughput with Flash Answers
- **Languages:** English, French, Spanish, German, Italian, Arabic, Russian, Simplified Chinese
- **License:** Apache 2.0 (Small version)

## Performance
- **Magistral Medium:** 73.6% on AIME2024, 90% with majority voting @64
- **Magistral Small:** 70.7% on AIME2024, 83.3% with majority voting @64
