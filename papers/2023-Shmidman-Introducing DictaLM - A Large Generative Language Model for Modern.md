## Abstract

First large generative language model (7B) for Modern Hebrew, trained on Hebrew-centric data. Establishes initial Hebrew LLM benchmarks for generation tasks.

## Data Description

Releases DictaLM (7B) and DictaLM-Rab foundation models for Modern and Rabbinic Hebrew under Creative Commons license, establishing initial Hebrew LLM generation benchmarks.
