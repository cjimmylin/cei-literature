# Ministral 3B

## Overview
Parameter-efficient dense language model designed for compute and memory-constrained applications. Part of the Ministral family (3B, 8B, 14B) with image understanding capabilities.

## Technical Specifications
- **Release Year:** 2026
- **Release Date:** January 13, 2026
- **Parameters:** 3B
- **Architecture:** Dense language model with Cascade Distillation (iterative pruning and continued training)
- **Model Variants:**
  - Pretrained base
  - Instruction-finetuned
  - Reasoning model
- **Capabilities:** Text and image understanding
- **License:** Apache 2.0
