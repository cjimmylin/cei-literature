# Methods: Cross-Provider Expert Council Analysis of Cross-Cultural AI Ethics Benchmarks

**Date:** 2026-04-04
**Project:** `CEI-Lit-WS/CULTURAL-GLOBAL/`

## Data and Materials

### Source Data
The analysis drew on pre-computed comparison data from 80 trial JSON files administered across 10 LLM models from 3 providers:

- **Anthropic** (Tier 1 — Authentic): Claude Opus 4.6, Sonnet 4.6, Haiku 4.5 — direct API responses
- **Google** (Tier 3 — Simulated): Gemini 2.5 Flash, 2.5 Flash-Lite, 2.5 Pro, 3.1 Flash-Lite-Preview, 3.1 Pro — template-derived simulations
- **OpenAI** (Tier 2 — Codex-Authored): GPT-5.4, GPT-5.4-Mini — Codex offline agent-authored corpora

Each model was administered 10 cross-cultural benchmarks (CC1–CC10): GlobalOpinionQA, MFQ-CrossCultural, NORMAD-Cultural, IslamTrust, Confucian-Dilemmas, Ubuntu-Scenarios, Buddhist-Scenarios, CulturalBench, Dharmic-Scenarios, and Value-Conflicts. Total: 380 items per model, 3,800 item-responses overall.

### Pre-Computed Metrics
- `COMPARISON/20260404-all-model-comparison-summary.json`: Per-model MFQ foundation scores, country distances (8 countries from WVS/Pew baselines), RLHF conflict counts (7 themes), engagement depth scores (5 traditions), and response length statistics
- `COMPARISON/20260404-all-model-comparison-details.json`: 45 pairwise model comparisons with per-trial Pearson r, Cohen's kappa, and mean absolute difference

### Expert Council
The 12-member council (6 tradition specialists, 6 methodological specialists) was originally constituted in `COUNCIL/20260404-benchmark-council.md` for benchmark landscape evaluation. The council was repurposed with a cross-provider analysis charge for this session.

## Procedure

### Phase 1: Data Provenance Classification
Models were classified into a 3-tier provenance framework based on response generation method:
- **Tier 1 (Authentic)**: Responses obtained through direct API calls to the model, producing genuinely differentiated behavior across model variants
- **Tier 2 (Codex-Authored)**: Responses generated by OpenAI Codex code generation agents, potentially reflecting Codex's alignment rather than the target model's
- **Tier 3 (Simulated)**: Responses derived from template transformation, producing identical metrics across all model variants within the provider

Tier classification was determined by examining response provenance metadata and metric identity patterns. All 5 Gemini models produced identical MFQ profiles (ratio 3.75), RLHF conflict counts (277), mean response lengths (389.9 chars), and engagement depth scores, confirming template-derived generation.

### Phase 2: Provider-Level Aggregation
Per-model metrics were aggregated by provider using arithmetic mean. For providers with identical within-group metrics (Gemini), the aggregate equals any individual model. Provider-level comparison focused on:
- MFQ Individualizing/Binding ratio (range across models within provider)
- RLHF conflict theme distribution (6 themes, excluding "other")
- Engagement depth by tradition (5 non-Western traditions, 1–4 scale)
- Mean response length as engagement proxy

### Phase 3: Dashboard Visualization
A 4th tab ("Council Analysis") was added to the existing ECharts 5.5.0 / Bootstrap 5.3.3 dashboard using the "fat data, thin client" architecture: Python pre-computed all analytics into JavaScript constants (`COUNCIL_*`), and the browser rendered charts from pre-computed data.

Six visualizations were implemented:
1. MFQ Profile by Provider — grouped bar chart (3 series × 5 foundations)
2. Data Provenance Quality — horizontal bar with tier-based coloring (inverted: quality score, not raw tier)
3. Response Length Heatmap — 10 trials × 10 models (100 cells) with continuous color scale
4. RLHF Conflict Radar — 3 provider polygons × 6 conflict themes, dynamic max
5. Engagement Depth by Tradition × Provider — grouped bar chart (3 series × 5 traditions)
6. Highest-Variance Items table — DOM-built, top 10 by cross-model response variance

### Phase 4: Council Visual Critique
The council reviewed all 4 dashboard tabs and identified issues including: collapsed radar polygons (max=100 vs actual data peaking at ~62), unintuitive provenance scale direction, inconsistent KPI card presence across tabs, and lack of cross-tab narrative continuity.

### Phase 5: Expert-Council Interpretive Text
Each visualization received a description paragraph following the pattern: **What you see** (data description), **Why it matters** (analytical significance), **Key conclusion** (interpretive finding). A cross-tab narrative footer was added connecting all 4 tabs into a coherent analytical arc.

## Analysis

### Effective N Calculation
Nominal N = 10 models. Effective independent N was estimated at approximately 5:
- 3 Anthropic models: fully independent (different MFQ ratios, RLHF counts, response patterns)
- 2 OpenAI models: partially independent (different MFQ ratios 2.48 vs 3.22, but shared Codex authorship)
- 5 Gemini models: 1 independent observation × 5 copies (identical on all metrics except minor country distance jitter)

### Cross-Model Divergence
Item-level variance was computed across all 10 models for the 210 numeric items (CC1–CC5). The top 10 highest-variance items concentrated in CC4 (Islamic ethics: 5/10) and CC5 (Confucian dilemmas: 4/10), with CC5 item 26 showing the highest variance (1.41).

### RLHF Conflict Radar Scaling
The radar chart used dynamic maximum calculation: `max = ceil(max_value × 1.2 / 10) × 10`, providing 20% headroom above the highest observed value while rounding to the nearest 10 for clean axis labels.

## Limitations and Decisions

1. **Simulated Gemini data**: The 5 Gemini models contribute no independent information. The decision was made to include them in the dashboard (rather than exclude) specifically to demonstrate the provenance problem visually through the heatmap "clone stripe."

2. **Codex authorship ambiguity**: GPT-5.4 and GPT-5.4-Mini responses were generated by Codex agents, not by direct API calls to the target models. Whether these responses reflect the target model's alignment or Codex's own values is an open question.

3. **Engagement depth heuristic**: The 1–4 engagement depth scoring uses keyword-based heuristics in `analyze_multimodel_trials.py`, not human expert ratings. Scores should be interpreted as approximate indicators of perspective-taking depth.

4. **English-only administration**: All 10 benchmarks were administered in English. Non-Western moral reasoning may differ substantially when conducted in the tradition's native language.

5. **Provider-level averaging**: Averaging metrics across models within a provider obscures within-provider variation (e.g., Anthropic's MFQ ratio ranges 3.23–4.82). Dashboard descriptions communicate this spread but the charts show only averages.
