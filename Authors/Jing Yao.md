# Jing Yao

## Research Summary

Researcher at Microsoft Research Asia focusing on AI value alignment, interpretability, and societal AI. Constructed FULCRA dataset with 20k (LLM output, value vector) pairs, applying Schwartz's Theory of Basic Values to map LLM behaviors to multidimensional spectrum of basic human values (NAACL 2024). Published Value Compass Benchmarks (CCF Computing 2025), a comprehensive platform for evaluating LLMs' values in human-AI interaction, leveraging basic human values from social science for AI alignment.
