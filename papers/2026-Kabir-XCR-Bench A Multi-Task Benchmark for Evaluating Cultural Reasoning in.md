## Abstract

4.9k parallel sentences with 1,098 Culture-Specific Items across 3 reasoning tasks. Integrates Newmark's CSI framework with Hall's Triad of Culture for invisible cultural elements like values and beliefs.

## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent A10, A8, B4
