## Abstract

Cultural LLM evaluation suite with 150 handcrafted prompts testing Filipino cultural knowledge and values. Created collaboratively by native Filipino speakers. Best model achieves only 46.0% vs native Filipino performance of 89.10%.

## Data Description

KALAHI: 150 handcrafted, culturally-grounded prompts created by native Filipino speakers testing LLMs on Filipino cultural knowledge and values, with both multiple-choice and open-ended evaluation settings.


## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent A6
**Relevance:** Core Filipino cultural values benchmark. Tests if LLMs can respond as cultural insiders. Reveals major gap between LLM and human cultural competence.
