# Mathstral

## Overview
Specialized 7B model fine-tuned for STEM subjects, particularly mathematical reasoning and scientific discovery. Released as tribute to Archimedes' 2311th anniversary, developed in collaboration with Project Numina.

## Technical Specifications
- **Release Year:** 2024
- **Release Date:** July 16, 2024
- **Parameters:** 7B
- **Base Model:** Mistral 7B
- **Context Window:** 32k tokens
- **Specialization:** Mathematical reasoning and STEM subjects
- **License:** Apache 2.0

## Performance
- **MATH Benchmark:** 56.6% (standard), 68.37% (majority voting @64), 74.59% (with reward model)
- **MMLU:** 63.47%
- State-of-the-art reasoning capacities in its size category for mathematical problems
