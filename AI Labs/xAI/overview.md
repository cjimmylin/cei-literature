## Mission and Philosophy

xAI was founded with the stated mission of understanding the true nature of the universe. The company emphasizes:

- **Maximally Truthful AI:** Prioritizing accuracy and honesty in AI responses
- **Curiosity-Driven:** Building AI that explores questions rather than avoiding them
- **Minimal Political Bias:** Aiming to reduce forced political correctness
- **Real-Time Knowledge:** Leveraging X platform integration for current information

## Grok Model Family

xAI has released multiple iterations of the Grok model family since 2023:

| Model | Year | Key Innovations |
|-------|------|-----------------|
| Grok-1 | 2023 | 314B MoE architecture, open-sourced (Apache 2.0) |
| Grok-1.5 | 2024 | 128k context window, improved reasoning |
| Grok-1.5V | 2024 | First multimodal (vision) capabilities |
| Grok-2 | 2024 | Advanced reasoning, image generation on X |
| Grok-3 | 2025 | 10x compute, DeepSearch, Think mode |
| Grok-4 | 2025 | 256k context, agentic capabilities |
| Grok 4.1 Fast | 2025 | 2M context window, top-tier tool calling |
| Grok Code Fast | 2025 | Specialized for agentic coding |

For detailed model specifications, see [[models|xAI Models]].

## Alignment and Safety Approach

xAI's publicly stated alignment approach includes:

1. **Constitutional AI Alternative:** Rather than extensive RLHF guardrails, xAI emphasizes truthfulness and intellectual honesty
2. **Transparency on Limitations:** Acknowledged uncertainty about capabilities
3. **Platform Safety:** Integration with X's existing content moderation systems
4. **Model Cards:** Safety information published for Grok-3 and Grok Code Fast
