# Mixtral 8x7B

## Overview
Sparse Mixture of Experts (MoE) model. High-performing open weights model with efficient inference. Outperforms Llama 2 70B on most benchmarks.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 0.1
- **Parameters:** 46.7B total, ~12B active
- **Architecture:** Sparse Mixture of Experts (SMoE)
- **License:** Apache 2.0
- **Format:** Safetensors (BF16)
