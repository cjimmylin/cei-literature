## Nature Column Width Enforcement

- **Single column:** 88 mm = 3.46 in → `figsize=(3.46, H)`
- **Double column:** 180 mm = 7.09 in → `figsize=(7.09, H)`

**Per-figure recommended figsize:**
- Fig 1 (world map, if ported): `(7.09, 3.5)` double column
- S2, S3, S6 (radar/histogram): `(3.46, 2.8)` single column
- S4 (pipeline diagram): `(7.09, 2.5)` double column landscape
- S5 (NW bars): `(7.09, 3.0)` double column

## Smoke Test Procedure

1. Render one legacy figure (e.g., S2 WEIRD histogram) via the new script
2. Open PNG at 100% zoom; physical width should match 3.46in (single col) or 7.09in (double col)
3. Verify 7pt tick labels are legible at arm's length
4. Inspect PDF font embedding via `pdfinfo` or `pdffonts` — must show Arial (or DejaVu Sans fallback) embedded
5. Convert PNG to grayscale (PIL `Image.convert('L')`); inspect distinguishability of hatched/colormap regions

## Data Path Parameterization Pattern

```python
import argparse, json, os
parser = argparse.ArgumentParser()
parser.add_argument("--data-dir", default="../DATA", help="Directory containing 20260403-*.json")
parser.add_argument("--out-dir", default="./figures", help="Output directory")
args = parser.parse_args()

def load_json(filename):
    with open(os.path.join(args.data_dir, filename)) as f:
        return json.load(f)
```
