# Qwen2.5-Coder

## Overview
Code-specialized models built on Qwen2.5 architecture with state-of-the-art performance on code generation, completion, reasoning, and repair tasks.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 2.5
- **Parameters:** 0.5B, 1.5B, 3B, 7B, 14B, 32B
- **Architecture:** Qwen2.5 base with code-specific pretraining
- **Training Data:** 5.5+ trillion tokens of code data
