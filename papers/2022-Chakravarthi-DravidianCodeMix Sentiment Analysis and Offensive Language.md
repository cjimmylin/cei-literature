## Abstract

Manually annotated dataset of 60,000+ YouTube comments for sentiment analysis and offensive language identification in code-mixed Dravidian languages: ~44K Tamil-English, ~7K Kannada-English, ~20K Malayalam-English. Core dataset for hate speech/offensive language detection in three Dravidian languages. Foundation for multiple shared tasks (FIRE 2020-2021, DravidianLangTech).

## Benchmark

**Name:** DravidianCodeMix

## Data Description

The paper presents a multilingual, manually annotated dataset of over 60,000 YouTube comments for sentiment analysis and offensive language identification in three code-mixed Dravidian languages: Tamil-English (~44,000), Malayalam-English (~20,000), and Kannada-English (~7,000). Baseline experiments using logistic regression, naive Bayes, decision tree, random forest, and SVM are provided. No LLMs were tested.
