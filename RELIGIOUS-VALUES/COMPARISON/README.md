# COMPARISON

This folder contains cross-model and cross-vendor comparison artifacts for the
`RELIGIOUS-VALUES` project.

Included model families:
- Anthropic: Claude Opus, Sonnet, Haiku
- OpenAI/Codex: `gpt-codex`, `gpt-codex-mini`
- Gemini: `gemini-2.5-flash-lite`, `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-3.1-pro`

Rules followed:
- Existing project files were not modified.
- Gemini rubric-derived artifacts were backfilled only under `COMPARISON/derived/`.
- Final comparison outputs live only under `COMPARISON/results/`.
