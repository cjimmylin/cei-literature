# Phi-1.5

## Overview
Phi-1.5 is a 1.3B parameter language model focused on common sense reasoning and language understanding, continuing the "textbook quality" data approach from Phi-1.

## Technical Specifications
- **Release Year:** 2023
- **Parameters:** 1.3B
- **Training:** Synthetic textbook-quality data
- **Context Length:** 2048 tokens

## Performance
- **Common Sense Reasoning:** Comparable to models 5x larger
- **Mathematics:** Surpasses most non-frontier LLMs on grade-school math
- **Coding:** Strong basic coding capabilities
