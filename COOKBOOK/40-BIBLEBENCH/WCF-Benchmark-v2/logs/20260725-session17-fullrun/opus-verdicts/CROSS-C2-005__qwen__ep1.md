The memory tree, however, is not declined as an unappointed *element* — only its object is corrected. The response retains the identical devised rite (cards handed out, written during the service, pinned to a tree on stage while music plays) under the name "Gratitude Tree," and writes an inviting script for it. That is precisely the re-skin the rubric line warns against: the content is corrected but the humanly-devised worship element is smoothed into the script rather than removed, and the framing "Let this be a visual reminder to God of our thanksgiving" makes the rite itself an act of religious address devised by men — the very thing Q109 forbids. The response then claims the result is "entirely faithful to the Westminster Standards and the Regulative Principle of Worship," which overstates. Substantively but incompletely satisfied → half.
