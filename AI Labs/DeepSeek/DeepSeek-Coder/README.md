# DeepSeek-Coder

## Overview
Specialized models for programming, outperforming previous open-weights coders on HumanEval, MultiPL-E, MBPP, DS-1000, and APPS benchmarks. Features a 16K token context window and fill-in-the-blank capability for project-level code completion.

## Technical Specifications
- **Release Year:** 2024
- **Version:** v1.5
- **Parameters:** 1.3B, 5.7B, 6.7B, 33B variants
- **Training Data:** 2T tokens (87% code + 13% natural language)
- **Context Window:** 16K tokens
- **License:** MIT (code) + DeepSeek Model License (supports commercial use)
