# Qwen2.5

## Overview
Current flagship open-source series with major boosts in mathematics, coding, and logical reasoning benchmarks.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 2.5
- **Parameters:** 0.5B, 1.5B, 3B, 7B, 14B, 32B, 72B
- **Context Window:** 128K tokens (native), up to 1M with Qwen2.5-1M variants
- **Architecture:** Transformer with GQA, SwiGLU, RoPE, RMSNorm
- **Training Data:** 18 trillion tokens
- **Specializations:** Qwen2.5-Coder, Qwen2.5-Math available
