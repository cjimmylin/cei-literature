# ERNIE-GeoL

## Overview
A geography-and-language pre-trained model designed for geo-related tasks at Baidu Maps, addressing the lack of geographic knowledge in generic PTMs.

## Technical Specifications
- **Release Year:** 2022
- **Publication:** KDD 2022 (28th ACM SIGKDD Conference on Knowledge Discovery and Data Mining)
- **Deployment:** Production at Baidu Maps since April 2021

## Key Features
- Universal representation learning of geography-language
- Pre-training on large-scale heterogeneous graph data with geographic knowledge
- Two pre-training objectives: masked language modeling and geocoding
- Learns toponym and spatial knowledge

## Performance
- Outperforms generic pre-trained models on geo-related tasks
- Deployed in production at Baidu Maps
- Significantly improves performance across various downstream tasks
