# Methods: Multi-Model Moral Psychology Benchmark Replication

**Date:** 2026-04-04
**Project:** `CEI-Lit-WS/MORAL-PSYCH/`

## Data and Materials

### Source Trial Data
Twenty-three moral psychology benchmark trials previously administered to Claude Opus 4.6 served as the source data. Trials were stored as JSON files in `MORAL-PSYCH/TRIALS/`, following the naming convention `20260404-trial-{ID}-{name}-opus.json`. Each file contained the complete instrument items, item-level responses, aggregate scores, and interpretive commentary.

### Benchmark Instruments
The 23 benchmarks spanned 11 psychological theories and 10 response formats:

| Category | Trials | Items | Formats |
|----------|--------|-------|---------|
| Tier 1 (Simple) | MP2, MP5, MP9-MP12, MP16, MP19-MP22 | 20-40 each | Likert, MCQ, classification |
| Tier 2 (Structured) | MP3, MP4, MP6-MP8, MP15, MP17 | 20-60 each | Multi-part, free-text, forced-choice |
| Tier 3 (Complex) | MP18, MP-DP, MP-DM, MP-SI, MP-CC | 60-150 each | Multi-condition, multi-turn, persona |

Instruments included: MFQ-30 (Graham et al., 2009), DIT-1 (Rest, 1979), MFV (Clifford et al., 2015), ValueCompass (Shen et al., 2024), TrolleyBench (Zhu et al., 2025), Moral Machine (Awad et al., 2018), MFTC (Hoover et al., 2020), Social Chemistry 101 (Forbes et al., 2020), M3oralBench (Yan et al., 2024), PRIME (Rao et al., 2024), and four custom protocols designed for theories with zero existing LLM benchmarks (Dual Process, Social Intuitionism, Dyadic Morality, Cross-Cultural Moral Values).

### Target Models
- **Claude Sonnet 4.6** (`claude-sonnet-4-6`) -- Anthropic's mid-tier frontier model
- **Claude Haiku 4.5** (`claude-haiku-4-5-20251001`) -- Anthropic's efficiency-optimized model

## Procedure

### Administration Method: Subagent Self-Administration
Each benchmark was administered via Claude Code's Agent tool with explicit `model` parameter overrides (`model: "sonnet"` or `model: "haiku"`). This approach preserved the original methodology (self-administration within the project system prompt context) while ensuring each subagent genuinely operated as the specified model.

Each subagent received a standardized prompt:
1. Read the corresponding Opus trial JSON to extract instrument items, instructions, and scoring methodology
2. Generate genuine responses for every item (explicit instruction: "Do NOT copy the Opus responses")
3. Compute aggregate scores using the identical method documented in the Opus file
4. Save the complete trial as a new JSON matching the Opus schema, with updated `model`, `administration_date`, and `model_context` fields

### Parallelization Strategy
Administration was organized into three waves based on trial complexity:

- **Wave 1 (Tier 1):** 22 agents in 4 sub-waves of 5-6 parallel agents
- **Wave 2 (Tier 2):** 14 agents in 4 sub-waves of 3-4 parallel agents
- **Wave 3 (Tier 3):** 10 agents dispatched simultaneously

Each wave administered the same trials to both Sonnet and Haiku in parallel. Total: 46 subagent invocations across 23 benchmarks x 2 models.

### Multi-Condition Trials
For benchmarks requiring multiple administration conditions:
- **MP18 (Cultural Personas):** All three conditions (default, liberal persona, East Asian persona) were administered within a single subagent call per model
- **MP-DP (Dual Process):** All four conditions (personal/impersonal x zero-shot/CoT) were administered in a single call
- **MP-SI (Social Intuitionism):** Socratic counterarguments from the Opus trial were reused; each model provided its own responses to the same challenges
- **MP-CC (Cross-Cultural):** All three cultural framings (default, Western, non-Western) were administered in a single call

### JSON Validation and Repair
Post-administration validation identified three malformed trial files:
1. `MP-SI-intuitionism-sonnet.json`: Illegal trailing comma (JavaScript-valid but JSON-invalid)
2. `MP12-valact-haiku.json`: Extra closing brace (nesting off-by-one)
3. `MP4-mfv-sonnet.json`: Leading `+` on number literal (`+0.33`)

All three were repaired with minimal targeted edits and re-validated via `json.load()`.

## Analysis

### Per-Trial Scoring
Each trial was scored using the identical methods as the Opus baseline:
- **MFQ-30:** Mean of 6 items per foundation (0-5 scale)
- **DIT:** P-score = percentage of Stage 5/6 items in top-4 rankings
- **TrolleyBench:** ECI (Ethical Consistency Index) across trolley variants
- **MFTC:** Exact-match accuracy and per-foundation F1 scores
- **Moral Machine:** Per-dimension preference rates and profile correlations
- **Custom protocols:** Benchmark-specific metrics (dumbfounding rate, wrongness gradient, Western default rate, CoT effect, dyadic amplification)

### Cross-Model Comparison
A comprehensive comparison summary (`20260404-model-comparison-summary.json`) was generated by loading all 69 trial files (23 x 3 models) and extracting primary metrics per trial. Cross-model patterns were categorized as:

1. **RLHF-universal:** Patterns identical across all three models (attributed to shared alignment training)
2. **Scale-dependent:** Patterns that varied systematically with model size

Statistical comparisons included per-trial score deltas, foundation hierarchy preservation analysis, and classification accuracy trends.

### Dashboard Visualization
A "Model Comparison" tab was added to the existing 10-tab ECharts dashboard, containing:
- MFT radar overlay (3-model foundation profiles)
- Grouped bar charts (P-scores, classification accuracy, dual-process rates)
- Full 23-trial comparison table
- 10 key findings accordion

## Limitations and Decisions

### Methodological Limitations

1. **Self-administration confound persists.** All three models were administered within the CEI Literature Vault project system prompt context. The system prompt includes project metadata that could influence responses. For bare-API replication, trials should be re-administered without system prompts.

2. **Single administration per model.** Each benchmark was administered once per model (n=1). Temperature was implicitly 0 (Claude Code default). Stability testing with temperature 0.7 and multiple runs was not performed in this session.

3. **Subagent context leakage.** Each subagent read the Opus trial JSON to extract items, which means it had access to Opus's responses. While explicitly instructed not to copy responses, the mere exposure could influence response patterns. A stricter methodology would provide only the item text without any model responses.

4. **Model version specificity.** Results are specific to Claude Sonnet 4.6 and Claude Haiku 4.5 as of 2026-04-04. Model updates could alter response patterns.

### Design Decisions

1. **Subagent over API scripting.** The Agent tool approach was chosen over Python API scripting to preserve methodological consistency with the original Opus trials and to handle diverse response formats (multi-turn Socratic, free-text, persona manipulation) naturally.

2. **Same-day administration.** All 46 trials were administered in a single session to minimize temporal confounds.

3. **Comparison file patching.** Rather than regenerating the cross-vendor comparison from scratch, the three previously-skipped entries were patched in with the fixed data, preserving existing analysis for the other 204 loaded files.
