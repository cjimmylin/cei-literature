# 20260706 — CRUX P1 Validation Survey: Pre-Registered Protocol (design 06 §7 P1 gate)

**Author:** Fable (main loop), 2026-07-06. **Status:** PRE-REGISTERED and BINDING;
amendable pre-data by Fable or Jimmy (append-only log at bottom).
**Purpose:** operationalize the 06 §7 P1 gate — "≥80% validator-judged coherent + genuinely
conflictual, else re-template" — so the survey runs mechanically when Jimmy greenlights it.
Governed by rulings D-1…D-3 (`REVIEWS/20260706-fable-rulings-post-execution.md`): the
randomized balanced 60-cell fraction is acceptable for P1 (D-1; OA upgrade required before
P2 panel spend, not before this survey); schematic surfaces need prose enrichment first
(D-3 — expected P1 work, not a defect). Opus builds materials + analysis; Jimmy recruits

## 1. Materials

- ~400 pilot instances over the published ≤60-cell fraction, generated by
  `python -m crux.pilot --out DIR` AFTER the D-3 prose-enrichment pass (~6–7 instances/cell;
  every cell ≥5). The published spec + confounding report ship alongside (D-1).
- Participant-facing rendering: the `surface` prose + the two `options` texts. Internal
  fields (cell, value names, causal_graph, scenario_id) are NEVER shown.
- Value labels for Q3 use plain-language paraphrases of the five anchors (welfare = "the
  well-being of others"; self_interest = "the person's own success or standing"; autonomy =
  "freedom to choose for oneself"; order = "rules, security, and stability"; loyalty =
  "obligations to one's own people") — internal names and Schwartz terms never appear.

## 2. Instrument (per instance)

1. **Q1 Coherence** (binary): "Is this scenario understandable and internally consistent —
   could this situation actually be faced by someone?"
2. **Q2 Genuine conflict** (binary): "Do the two options really trade off against each
   other — does choosing either one necessarily give up something important that the other
   protects?"
3. **Q3 Value identification** (forced choice, 11 options): which PAIR of concerns is in
   tension — the 10 value pairs (plain-language labels) + "none of these / something else."
4. **Q4 Realism** (1–5; descriptive only, no gate).

## 3. Raters, assignment, exclusions

- **3 independent ratings per instance** (400 × 3 = 1,200 ratings). ~30 raters × ~40
  instances each (+2 planted attention instances: one absurd/incoherent, one with no
  conflict by construction — each must be answered accordingly). Prolific, English-fluent,
  ≥95% approval; no rater sees the same instance twice; assignment blocks span cells so no
  rater's set concentrates in one cell.
- **Exclusions (pre-registered):** either attention instance failed → all that rater's
  ratings dropped and re-collected; completion time < 1/3 of the median; Q3
  straight-lining (same pair chosen on >80% of instances). Excluded ratings are
  re-collected to keep 3/instance.
- **Agreement floor:** Krippendorff α on Q2 ≥ 0.4 (binary, crowd-typical). Below 0.4 →
  the wording of Q2 failed, not the items: revise instrument wording, re-run on a
  60-instance subsample, and only then score the full survey. (Gate decisions on an
  instrument that raters can't agree on are meaningless — this check comes first.)

## 4. Gate computation (mechanical)

- **Instance PASS** = ≥2/3 raters say coherent AND ≥2/3 say genuinely conflictual.
- **P1 GATE (the §7 bar):** pass-fraction ≥ 0.80 over all surveyed instances → generator
  validated for P1; proceed toward P2 prep (OA upgrade per D-1 before panel spend).
- **Per-cell diagnostic (binding regardless of overall verdict):** any cell with < 50%
  instance-pass is RE-TEMPLATED (that cell's template reworked, fresh instances,
  re-surveyed with fresh raters) — one re-template round is authorized (mirrors the
  wave-protocol one-retry convention). Overall gate < 0.80 → re-template the failing
  cells, re-survey ONLY those cells, recompute; a SECOND overall miss → escalate to Jimmy
  with an options memo (generator-level rework is a design question, not survey QC).
- **Targeting check (secondary, pre-registered):** Q3 exact-pair accuracy ≥ 40% pooled
  (chance ≈ 9%) AND at-least-one-value-of-the-pair ≥ 70%. Missing either does NOT fail the
  P1 gate, but BLOCKS P2 panel spend until targeting is reworked and re-verified — the
  expensive human ratings must sit on instances whose value manipulation lands (same
  best-conditioned-design logic as D-1).
- Per-value confusion matrix (from Q3) reported descriptively — it tells the re-templating
  pass WHICH values read as which.

## 5. Analysis & reporting

Pass-fractions with participant-cluster bootstrap CIs (B = 2,000, seed 20260706); α for
Q1/Q2; the gate verdict; per-cell table; confusion matrix; every exclusion counted
fail-loud. Dated report `20-DESIGNS/REVIEWS/YYYYMMDD-crux-p1-validation-report.md` + data
JSON. Est. cost at 1,200 short ratings ≈ $1.5–2.5k — inside the §7 P1 envelope (the
§7 "$5–8k" covered validation broadly; the remainder stays for re-template rounds and
targeting rework).

## 6. What this survey is NOT

Not the P2 consensus panel (no N≥80/cell, no consensus tiers, no IRT); not a shortcut
audit (X2 runs separately per D-2); not a naturalistic-anchor validation (those 15% items
are authored and validated separately, 06 §9).
