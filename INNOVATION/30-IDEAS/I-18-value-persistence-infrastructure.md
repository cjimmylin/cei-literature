# I-18 — Value-Persistence Infrastructure

**Tier 3** · **Gaps: G-18** · **Programs: RP-05 DRIFTLAB** · **Kernel:** Fable 5, 2026-07-07 (FROZEN) · **Body:** Opus draft 2026-07-07

## The idea                        [KERNEL — FROZEN]

An infrastructure layer is emerging for value continuity in long-lived agents — memory-governance taxonomies naming "memory drift," identity-file architectures anchoring values across sessions, first cross-sectional agent-value benchmarks — all making stability claims that nothing can currently test.

## Key results

- **Memory-governance taxonomy** (SSGM; 2603.11768 — SEARCH-CONFIRMED): stability/validity/efficiency/safety framework that explicitly names "memory drift."
- **Identity-file architectures** (⚠ 2604.09588 — ⚠ UNCONFIRMED): cross-session value-continuity anchors ("if values shift with context management, alignment is a moving target").
- **Cross-sectional agent-value benchmark** (⚠ 2605.10365, Agent-ValueBench — ⚠ UNCONFIRMED): measures agent values statically — a snapshot camera pointed at a moving object.
- **Computer-use / persistence benches** (SEARCH-CONFIRMED / ⚠): VPI-Bench (2506.02456 — SEARCH-CONFIRMED); LPS-Bench (⚠ 2602.03255 — ⚠ UNCONFIRMED).
- **Mechanistic correlate** (⚠ 2601.10387, Assistant Axis — ⚠ UNCONFIRMED): distance from the trained default persona predicts harmful-response rates; long conversations drift along it — a persona-geometry hook (see I-02).

## Mechanisms & caveats

The whole layer makes *stability* claims (this architecture anchors values; this memory scheme resists drift) with no validated longitudinal instrument to test them — the measurement vacuum is the opportunity. Existing benches are cross-sectional; the Assistant-Axis work is mechanistic and lab-internal; long-conversation degradation is anecdotal and unquantified. The candidate causal driver — memory/context *composition* rather than raw turn count — is a hypothesis (RP-05 H2), not an established result. Most infrastructure citations here are ⚠ UNCONFIRMED same-month IDs; verify before external use. COOKBOOK sketch S1 DRIFT anticipated this topic.

## Implications for CEI practice   [KERNEL — FROZEN]

(a) RP-05 DRIFTLAB is the missing test: architectures claiming stability become its highest-value experimental conditions. (b) Cross-sectional agent benchmarks (Agent-ValueBench) are complements, not competitors — CEI's edge is longitudinal + unannounced. (c) Memory composition (what accumulated) over turn count is the causal hypothesis (RP-05 H2) — design conditions accordingly. (d) If an identity architecture is adopted by a major framework, test it first — validation demand will follow adoption.
