## Abstract

Interactive installation exploring how 'large language objects' (LLOs) using GPT-4 Vision can mediate animistic relationships with everyday objects. Draws on animist worldviews including Shinto to create ritual-like AI interactions. Argues that AI's opacity invites animistic interpretation, allowing LLMs to re-enchant the mundane.

## Data Description

This paper does not introduce a formal dataset or benchmark. It describes an interactive installation using GPT-4 Vision as 'large language objects' (LLOs) to mediate animistic relationships with everyday objects, drawing on Shinto-inspired animist worldviews to create ritual-like AI interactions.
