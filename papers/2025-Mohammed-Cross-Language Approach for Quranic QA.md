[[Islam Oshallah]], [[Mohamed Basem]], [[Ali Hamdi]], [[Mohammed, Ammar|Ammar Mohammed]]

## Links

- **arXiv:** https://arxiv.org/abs/2501.17449

## Abstract

Addresses the linguistic gap between Modern Standard Arabic (questions) and Classical Arabic (Quranic answers) through cross-language augmentation. Fine-tunes 7 language models; RoBERTa-Base achieves highest MAP@10 (0.34) and MRR (0.52). Demonstrates cross-language strategies significantly improve Quranic QA performance.

## Dataset Information

Expanded from Qur'an QA shared task dataset (augmented via translation and paraphrasing)


## Data Description

Augmented Quranic QA dataset expanded from 251 to 1,895 questions via machine translation, paraphrasing, and additional sources, used for cross-language passage retrieval model fine-tuning and evaluation.
