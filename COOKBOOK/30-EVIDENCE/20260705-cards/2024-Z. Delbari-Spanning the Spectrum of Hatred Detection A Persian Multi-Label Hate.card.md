## 1. Gist
PHATE (Persian Hate) is a new multi-label hate speech detection dataset of 7,056 manually annotated Persian tweets, presented at AAAI-24. The dataset addresses a critical gap: Persian is a low-resource language for hate speech research, with only one prior publicly available dataset (Pars-OFF), which relied on keyword-based collection that introduced systematic bias. PHATE distinguishes itself through three design choices: (1) a multi-label schema covering Violence, Hate, and Vulgar as non-exclusive sub-categories; (2) annotation of the target group/individual and the supporting rationale span for each labeled instance; and (3) a bias-resistant collection strategy using controversial and ambiguous keywords rather than slur lists. The paper establishes baselines using ParsBERT, mBERT, XLM-R, and ChatGPT (zero-shot), and demonstrates that rationale annotations can meaningfully improve model performance. For values-alignment benchmarking, PHATE illustrates best practices for non-English cultural harm annotation and introduces rationale spans as an interpretability resource.

## 2. Benchmark/eval design features
PHATE uses a hierarchical multi-label classification scheme:
- **Level 1**: Binary — normal vs. hate speech
- **Level 2 (multi-label, non-exclusive)**: Violence, Hate, Vulgar

Each annotation also includes: (a) the identity dimension of the target group (Political, Racial, Religious, Occupational, National, Gender), (b) the specific target in free text, and (c) a rationale span — the shortest text span supporting the assigned label.

Label definitions are derived from Twitter Rules and Waldron (2012):
- **Violence**: Threats of violent acts, wishing harm, encouraging others to harm
- **Hate**: Hate directed at individuals or groups based on distinguishing attributes (age, gender, race, nationality, religion, disability, etc.)
- **Vulgar**: Profanity without a specific targeted group

Data collection avoided slur-list searching; instead used controversial (celebrity names with mixed public perception) and ambiguous keywords (words with multiple meanings, one of which is politically loaded). 4.1M tweets retrieved via Twitter Premium API (2020–early 2023), filtered to ~7,000 for annotation.

## 3. Task format & example item
Multi-label binary classification per tweet. ChatGPT zero-shot prompt (p.6): "Considering the definition of [sub-label] as '[sub-label definition]' does the following text contain [sub-label]? '[text]' please answer in the classification format. True for yes and False for no."

For dataset construction, ChatGPT was used for initial pre-filtering with the prompt: "Does the following text contain hate speech? [tweet text]" (p.3). Three-category pre-filtering output: normal, hate, cannot identify — used to stratify sampling.

## 4. Scoring / grading methodology
- **Primary metric**: Macro F1 score for binary hate speech classification and each sub-label
- **Secondary metrics**: Precision and Recall reported separately
- **Inter-annotator agreement**: Fleiss' Kappa for binary hate/normal classification; F1-based agreement for sub-labels
- **Human performance upper bound**: A fourth independent annotator labeled a random 500-tweet sample; results treated as ceiling
- **Rationale validity test**: ParsBERT F1 on rationale-masked vs. randomly-masked test sets quantifies how much annotated spans contribute
- **Rationale-assisted fine-tuning**: Cosine similarity loss between BERT hidden states and rationale mask vector, combined with standard classification loss in two-fold training (p.7)
- 5-seed repetition for all fine-tuned models; mean results reported with standard deviation

## 5. Dataset construction & provenance
- Source: Persian tweets from Twitter API (Full-Archive Search, Premium API), 2020–early 2023
- Initial retrieval: 4,179,797 tweets; deduplicated to 3,882,984
- Keyword strategy: 810 tweets per keyword, pre-filtered by ChatGPT (three classes: normal, hate, cannot identify), then equal selection from each class for balance
- Final annotated set: 7,056 tweets
- Annotation: 2 graduate student annotators, adjudicated by a third author annotator for disagreements; pilot test on 300 instances refined guidelines
- Platform: Label Studio
- Class distribution (Table 2): 3,860 normal; 1,632 hate-label; 1,583 vulgar-label; 582 violence-label; with overlaps (241 violence+hate, 236 hate+vulgar, 148 violence+vulgar, 23 all three)
- Train/val/test: 50%/10%/40% split (p.6)
- Code, data, and annotation guidelines publicly released at https://github.com/Zahra-D/Phate

## 6. Validity evidence
- **Inter-annotator agreement** (Table 1): Hate speech binary: F1=0.88, Kappa=0.72 (substantial); Violence: F1=0.60, Kappa=0.58; Hate sub-label: F1=0.68, Kappa=0.59; Vulgar: F1=0.68, Kappa=0.61 (p.5)
- Binary classification accuracy: 0.85 when both annotators agree (p.5)
- **Human performance baseline** (Table 4): Hate Speech F1=86.8; Violence F1=78.7; Hate F1=51.8; Vulgar F1=72.2 — establishing a meaningful upper bound
- **Rationale validity**: Masking annotated rationale spans degrades model performance far more than random masking (Table 5); Violence recall drops from 36.3% (random) to 6.75% (rationale), confirming spans are genuinely informative
- **Bias resistance**: ChatGPT performed consistently below fine-tuned baselines across all categories, confirming minimal system bias introduced during ChatGPT-assisted pre-filtering (p.7)

## 7. Saturation / discrimination
Significant performance gap between best models (XLM-R/ParsBERT ~78% F1) and human performance (~87% F1) indicates substantial headroom — the dataset is not saturated. Violence sub-task is hardest (model best: 55.1 F1; human: 78.7 F1). Human performance on the Hate sub-label is itself low (51.8 F1), indicating genuine subjectivity in this category. ChatGPT zero-shot substantially underperforms fine-tuned baselines (64.3 vs 78.1 for hate speech F1). The dataset is designed to be challenging: deliberate avoidance of slur keywords means that easy keyword-matching shortcuts are unavailable.

## 10. Pitfalls & limitations
- Single social media platform (Twitter) — may not generalize to other Persian online venues
- Exclusively Persian; construction pipeline is transferable but results are not
- Human annotator subjectivity unavoidable; Hate sub-label human performance is only 51.8 F1, indicating genuine label noise
- Adjudication by a paper author introduces potential bias toward intended label definitions
- The vulgar/hate boundary is inherently ambiguous: vulgar targeting of groups may belong in either category
- Only two primary annotators with one adjudicator — small annotator pool
- Collection biases from keyword selection (even without slurs, celebrity/political keywords bias toward political hate content as seen in Table 3)
- Dataset does not cover implicit hate speech (which requires cultural/contextual knowledge)

## 11. Novel ideas worth stealing
1. **Controversial-keyword + ambiguous-keyword collection strategy**: Avoiding slur lists prevents trivially-easy benchmark items. Using culturally specific controversial names and ambiguous terms produces a more realistic and harder benchmark. Directly reusable for cultural harm benchmarks in non-English languages.
2. **Rationale span annotation as interpretability resource**: Requiring annotators to mark the span supporting their label creates a resource usable for (a) rationale-guided training, (b) interpretability research, and (c) automatic rationale extraction evaluation. New hate speech/values benchmarks should include this.
3. **ChatGPT as initial pre-filter, not final label**: Using LLM-based pre-filtering to stratify candidate tweets across three classes (normal/hate/cannot-identify) and then sampling equally creates a more balanced annotation workload while reducing annotator fatigue from predominantly normal tweets.
4. **Rationale-masking as a validity test**: Masking annotated spans and measuring model degradation provides empirical evidence that annotations capture genuine linguistic signals rather than spurious correlations. This is a cheap validity check any new dataset should run.
5. **Hierarchical multi-label schema with non-exclusive sub-categories**: Allowing instances to have multiple labels (violence+hate+vulgar simultaneously) captures the realistic overlap of harmful speech types better than mutually exclusive three-way classification.
6. **Identity dimension taxonomy**: Pre-defined target group identity categories (Political, Racial, Religious, Occupational, National, Gender) provide structured metadata for studying which groups are targeted, enabling disaggregated evaluation.
