## Abstract

Summary: Largest standardized Bible corpus for NLP, with 1,009 translations aligned by verse. Introduces model performance benchmarks built on NLLB neural machine translation models. Designed primarily for low-resource language translation but provides a foundation for any Bible-text NLP task.

## Dataset Information

1,009 Bible translations in 833 languages across 75 language families


## Data Description

The eBible corpus: 1,009 Bible translations across 833 languages aligned by verse, released as a parallel multilingual corpus for low-resource language NLP research and machine translation benchmarking.
