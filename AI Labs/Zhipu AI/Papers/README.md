# Zhipu AI / THUDM Research Papers

This directory contains foundational research papers from Zhipu AI and Tsinghua University's Data Mining (THUDM) group.

## Core GLM Papers

| Paper | arXiv | Year | Description |
|-------|-------|------|-------------|
| GLM: General Language Model Pretraining with Autoregressive Blank Infilling | [2103.10360](https://arxiv.org/abs/2103.10360) | 2021 | Original GLM architecture paper |
| GLM-130B: An Open Bilingual Pre-trained Model | [2210.02414](https://arxiv.org/abs/2210.02414) | 2022 | 130B parameter open bilingual model |
| ChatGLM: A Family of Large Language Models from GLM-130B to GLM-4 All Tools | [2406.12793](https://arxiv.org/abs/2406.12793) | 2024 | Comprehensive technical report covering ChatGLM series |

## Vision-Language Models

| CogAgent: A Visual Language Model for GUI Agents | [2312.08914](https://arxiv.org/abs/2312.08914) | 2023 | Vision-language model for GUI automation |
