## Abstract

First NepaliGPT benchmark dataset with 4,296 QA pairs in Nepali. Achieves perplexity of 26.32, ROUGE-1 of 0.2604, causal coherence of 81.25%. First generative language model for Nepali with associated benchmark dataset.

## Benchmark

**Name:** NepaliGPT

## Data Description

NepaliGPT introduces the Devanagari Corpus (9.3 GB, 383M tokens) for pretraining and a 4,296 QA-pair Nepali benchmark dataset for fine-tuning and evaluation; no public repository URL is provided in the paper.
