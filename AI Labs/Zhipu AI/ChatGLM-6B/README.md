# ChatGLM-6B

## Overview
Lightweight bilingual dialogue model optimized for consumer-grade GPUs, enabling high-quality local deployment.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 1.0
- **Parameters:** 6B
