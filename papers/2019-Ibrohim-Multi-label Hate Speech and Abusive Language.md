## Abstract

Hate speech and abusive language spreading on social media need to be detected automatically to avoid conﬂicts between citizens. Moreover, hate speech has a target, category, and level that also need to be detected to help the authority in prioritizing which hate speech must be addressed immediately. This research discusses multi-label text classiﬁcation for abusive language and hate speech detection including detecting the target, category, and level of hate speech in Indonesian Twitter using machine learning approaches with Support Vector Machine (SVM), Naive Bayes (NB), and Random Forest Decision Tree (RFDT) classiﬁer and Binary Relevance (BR), Label Power-set (LP), and Classiﬁer Chains (CC) as the data transformation method. We used several kinds of feature extractions which are term frequency, orthography, and lexicon features. Our experiment results show that in general the RFDT classiﬁer using LP as the transformation method gives the best accuracy with fast computational time.

## Data Description

The paper builds a multi-label Indonesian Twitter dataset of 13,169 tweets annotated for hate speech and abusive language, including hate speech target (individual/group), category (religion, race, physical/disability, gender, other), and level (weak/moderate/strong). Traditional ML classifiers (SVM, Naive Bayes, Random Forest) with three data transformation methods are evaluated, with Random Forest using Label Power-set achieving 77.36% accuracy for binary hate speech detection and 66.12% for the full multi-label task.
