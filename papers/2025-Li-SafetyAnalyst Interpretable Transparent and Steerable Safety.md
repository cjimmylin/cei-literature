## Data Description

SAFETYANALYST is an AI safety moderation framework that generates interpretable harm-benefit trees using chain-of-thought reasoning. The training dataset consists of 18.5 million harm-benefit features generated by frontier LLMs (GPT-4o, Gemini-1.5-Pro, Llama-3.1-70B-Instruct, Llama-3.1-405B-Instruct-Turbo, and Claude-3.5-Sonnet) on 19k prompts sampled from WildJailbreak, WildChat, and AegisSafetyTrain. The student model (Llama-3.1-8B-Instruct) was fine-tuned via supervised fine-tuning with qlora, and a separate 28-parameter aggregation model performs transparent harm-benefit scoring.
