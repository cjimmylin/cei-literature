## Abstract

Comprehensive evaluation scripts for robust and reproducible multilingual LLM evaluation in SEA languages. Covers 8 primary tasks with 14 datasets across generation, MCQ, and classification. Finds SEA-specialized LLMs still outperform general LLMs. Reproducible evaluation framework for Thai and SEA languages. Includes calibration techniques for better evaluation faithfulness.

## Benchmark

**Name:** SailCompass

## Data Description

Reproducible evaluation benchmark for Southeast Asian languages covering 8 tasks with 14 datasets across generation, MCQ, and classification for Indonesian, Vietnamese, and Thai.
