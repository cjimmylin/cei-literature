# DeepSeek LLM

## Overview
67B parameter model showing strong performance across major math and coding benchmarks. Features a standard dense architecture with Grouped-Query Attention. Trained on 2 trillion tokens of English and Chinese data.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 1.0
- **Parameters:** 67B
- **Architecture:** Grouped-Query Attention
- **Training Data:** 2 trillion tokens (English + Chinese)
- **License:** DeepSeek Model License (supports commercial use)
