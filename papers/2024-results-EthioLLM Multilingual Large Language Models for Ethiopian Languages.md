## Abstract

Multilingual LLMs for five Ethiopian languages with new EthioBenchmark dataset for downstream NLP tasks. Ethiopian languages are noted to be imbued with profound religious and cultural significance.

## Data Description

EthioBenchmark: evaluation dataset for five Ethiopian languages covering downstream NLP tasks; plus multilingual LLM models trained for Amharic, Tigrinya, Afaan Oromoo, Somali, and Wolaytta.
