# Automating News Comment Moderation with Limited Resources: Benchmarking in Croatian and Estonian

## Abstract

Benchmarks automatic classification of user comments for news moderation in Croatian and Estonian using real-world data. Tests multiple classifier architectures for offensive content detection.

## Data Description

Dataset of 60M+ reader comments from Croatian (24sata, Vecernji List) and Estonian (Eesti Ekspress) news outlets, with human moderator labels for blocked/allowed content across multiple offense categories.
