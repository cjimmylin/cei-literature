# A Dual-Layered Evaluation of Geopolitical and Cultural Bias in LLMs

## Abstract

Defines model bias (from training) and inference bias (from query language). Two-phase evaluation with factual QA and geopolitically sensitive disputes. Manually curated dataset in four languages including Chinese.

## Data Description

Proposes a dual-layered evaluation framework for geopolitical and cultural bias in LLMs, testing five models on bias detection tasks. The evaluation dataset and code are publicly available on GitHub.
