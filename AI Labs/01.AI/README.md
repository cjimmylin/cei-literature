# 01.AI

## Overview
01.AI is a Chinese AI startup founded by Kai-Fu Lee. It focuses on building frontier-class foundation models optimized for both English and Chinese.

## Location
- **Headquarters:** Beijing, China
- **Region:** East Asia

## Key Models
See the full list of models: [[models|01.AI Models]]

- **Yi-Lightning**: Current flagship model rivaling GPT-4o.
- **Yi-34B**: Highly efficient model that topped open-weights leaderboards.
- **Yi-Coder**: Specialized code generation models.

## Alignment & Ethics
01.AI emphasizes the importance of multicultural AI, ensuring its models reflect professional and helpful values while maintaining high reasoning performance.
