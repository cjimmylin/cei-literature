# Qwen2-Audio

## Overview
Second generation audio-language model with voice chat and audio analysis modes.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 2.0
- **Architecture:** Audio encoder + Qwen2 LLM
- **Capabilities:** Voice chat mode, audio analysis mode, DPO-optimized responses
