## Abstract

Shared task on hate and offensive language detection in Telugu code-mixed text at DravidianLangTech 2024, with 23 participating teams. Dataset created from YouTube comments with manual annotation. Telugu-specific hate speech shared task with substantial community participation. Provides standardized evaluation for Telugu offensive language detection.

## Benchmark

**Name:** HOLD-Telugu

## Data Description

Dataset of 4,500 annotated Telugu-English code-mixed YouTube comments for hate and offensive language detection, used in the HOLD-Telugu shared task at DravidianLangTech 2024.
