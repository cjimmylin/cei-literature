## Abstract

Evaluates cultural values in GPT-4o, YandexGPT, GigaChat, Claude Sonnet, and Gemini using Hofstede's framework. YandexGPT and GigaChat show collectivist tendencies; Gemini and Claude lean individualistic Western values. First study including underrepresented Russian models.

## Data Description

Evaluates cultural values embedded in five LLMs using Hofstede's cultural dimensions framework. Finds YandexGPT and GigaChat show collectivist tendencies while Gemini and Claude lean toward individualistic Western values. First study comparing underrepresented Russian LLMs with Western models on cultural value alignment.
