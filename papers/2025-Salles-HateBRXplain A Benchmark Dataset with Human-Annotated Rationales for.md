## Abstract

First benchmark dataset for hate speech detection in Brazilian Portuguese with human-annotated text span rationales. Evaluated using mBERT, BERTimbau, DistilBERTimbau, and PTT5 models for explainability using LIME and SHAP.

## Notes

**Source:** Culture/Nationality Benchmark Search (20260215), Agent Agent_18
**Relevance:** Benchmark for explainable hate speech detection in Brazilian Portuguese. While focused on hate speech rather than cultural values directly, it evaluates model alignment with Brazilian moral judgments about offensive content.
