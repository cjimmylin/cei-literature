## Abstract

Comprehensive morphological and syntactic annotation of the entire Quran using verified Tanzil.net text. Features 72 syntactic roles, detailed morphological analysis, and context-specific annotations by expert Arabic linguists using traditional i'rab methodologies. Available in TSV, SQLite, CSV, and JSON formats. Valuable for dependency parsing, grammar checking, MT, and text summarization of Classical Arabic.

## Dataset Information

131K+ morphological entries, 123K+ syntactic function instances, 72 syntactic roles


## Data Description

Comprehensive morphological and syntactic annotation of the entire Quran using verified Tanzil.net text, featuring 72 syntactic roles and expert Arabic linguistic analysis. Available in TSV, SQLite, CSV, and JSON formats for NLP tasks including dependency parsing and machine translation.
