**Scripts:** `PYTHON/discover_unknown_authors.py`, `PYTHON/apply_author_fixes.py`

**Note:** PDF extract author parsing is unreliable (~60% garbage). Prefer API sources (CrossRef, Semantic Scholar, OpenAlex) for author resolution.

### 3c. `authors_incomplete: true` — 136 papers

These papers were flagged during import as having incomplete author lists. Resolution requires API lookups to fetch full author lists.

**Script:** `PYTHON/resolve_incomplete_authors.py`

### 3d. Missing abstracts — 177 papers (8.8%)

177 papers have a blank `abstract` field. Some may be obtainable from APIs; others may genuinely lack abstracts (workshop papers, editorials, etc.).

### 3e. Blank `local_pdf` — 29 papers

29 papers have an ambiguous blank `local_pdf` field (neither `N/A` nor a wikilink). These should be resolved to either:
- A valid `[[PDFs/YYYY/filename.pdf]]` wikilink if the PDF exists
- `N/A` if no PDF is available

An additional 194 papers have `local_pdf: N/A` explicitly (no PDF acquired).

### 3f. `DATA_URL` formatting — 433 papers

433 papers have bare `NA` for `DATA_URL` instead of quoted `"NA"`. Functionally equivalent but inconsistent. Low priority cosmetic fix.
