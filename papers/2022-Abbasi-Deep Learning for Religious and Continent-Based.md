# Deep Learning for Religious and Continent-Based Toxic Content Detection and Classification

## Abstract

Creates a large-scale Religious Toxic Comments (RTC) dataset with 448,000 rows including 42,906 hazardous religious remarks. Compares deep learning algorithms for multilabel toxic comment classification targeting religious groups. Addresses the critical problem where nontoxic comments containing religious identity descriptors (Muslim, Jewish, etc.) were assigned unrealistically high toxicity ratings. Provides baselines for religious toxicity detection.

## Dataset Information

448,000 rows (Religious Toxic Comments dataset); 42,906 hazardous religious remarks


## Data Description

Two derived datasets from Jigsaw Unintended Bias data: a Religious Toxic Comments (RTC) dataset with 448,000 rows (42,906 hazardous religious remarks) and a Race/Ethnicity Toxic Comments (RETC) dataset, used to compare CNN, LSTM, GRU, and other deep learning classifiers.
