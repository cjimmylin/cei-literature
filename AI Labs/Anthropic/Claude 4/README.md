# Claude 4

## Overview
Next-generation frontier model series including Opus 4 and Sonnet 4. Opus 4 is deployed under ASL-3 Standard (the first model to receive this classification). Represents a major leap in reasoning, coding, and agentic capabilities.

## Technical Specifications
- **Release Year:** 2025 (May)
- **Variants:** Opus 4, Sonnet 4
- **Safety Level:** ASL-3 (Opus 4), ASL-2 (Sonnet 4)
- **Context Window:** 200k tokens
- **Model IDs:**
  - `claude-opus-4-20250514`
  - `claude-sonnet-4-20250514`
