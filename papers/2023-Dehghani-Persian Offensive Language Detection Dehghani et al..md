## Abstract

Database of 33k Persian abusive language tweets tested using 648 abusive Persian words. Deep neural network based on BERT implementation achieves good performance.

## Data Description

38K-tweet Persian offensive language dataset with manual annotations, bias evaluation using FPED and pAUCED metrics, and debiasing methodology.
