# T1.1 Venue Readiness Memo
**Author:** Scientific Publishing Strategist
**Date:** 2026-04-12
**Status:** Phase A planning memo

## Problem

The paper defers venue selection but must document its current state relative to three candidate venue families (Nature-family, PNAS-style, specialist like FAccT/JAIR/BD&S) to enable fast venue lock-in in a future session. Current format implicitly favors Nature-family via 600 DPI figures and APA-prose author-date references.

## Current State Measurements

| Metric | Current value | NHB limit | PNAS limit | Specialist limit |
|--------|--------------|-----------|------------|------------------|
| Abstract (long) | 523w | N/A | structured ~250w | varies |
| Abstract (compressed) | 150w | ≤150w ✓ | N/A | N/A |
| Reference count | 131 entries | ~50 hard | ~60 hard | none |
| Main text word count | 32,218w | ~5000 main | ~6000–8000 | usually unlimited |
| Endmatter components | 7 of 7 NHB-required | 7 required | varies | varies |
| Figures | 23 (16 main + 7 supp) | ≤6–8 main | ≤6 main | varies |
| Format | APA author-date prose | numbered (Vancouver) | numbered (NLM) | mixed |

## Options Considered

- **Option A — Nature Human Behaviour:** Highest prestige; strict 5000-word main text limit. Requires reference compression from 131 to ~50 (62% cut), figure reduction, possible section deletion. Achievable via eliminating the synthesis layer (06) and merging methods-results. Format conversion to Vancouver numbered refs. Endmatter fully compliant. **Risk:** loses granular benchmark detail. **Effort:** 12–15h.

- **Option B — PNAS:** Moderate prestige; flexible 6000–8000-word main + 1500-word SI limit. Reference target ~60 (54% cut). Allows retention of most results sections; permits longer supplementary file. Format conversion required. Endmatter partially compliant (CRediT + competing interests need extension). **Effort:** 8–10h.

- **Option C — Specialist (FAccT / JAIR / Big Data & Society):** Best content-fit; no hard word/ref limits. Retains full 131 refs, keeps APA format (these venues often accept author-date). Endmatter fully compliant. **Risk:** longer review cycle, narrower audience. **Effort:** 2–3h.

## Recommendation

**Keep current state; no source modifications this session.** This memo records numerical baselines so a future "venue lock-in" session can decide in <1h.

**Lock-in directionality:** Switching from current state to **specialist** is cheapest (~2h). Switching to **PNAS** is moderate (~8h). Switching to **NHB** is expensive (~15h) due to required main-text compression. The 600 DPI + APA-prose state implicitly favors Nature-family or specialist over numbered-ref venues like JAIR (where reverse APA→numbered conversion is harder than forward).

## Files Phase C Should Touch

None this session. All venue analysis is read-only. A future venue lock-in session will modify references, structure, captions, and endmatter.

- All three venue families evaluated with hour estimates
