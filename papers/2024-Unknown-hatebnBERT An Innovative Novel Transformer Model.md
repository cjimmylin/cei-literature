## Abstract

Introduces hatebnBERT, a BERT-based model tailored to Bangla for religious hate speech detection. Creates two datasets: binary (hate/not) and five-class categorization including Blasphemy and Ethnic Hatred. Achieves 98.8% accuracy (binary) and 98.6% (multiclass). Addresses Bangla-specific religious sensitivity challenges between Muslim and Hindu communities.

## Dataset Information

Binary classification dataset + five-class dataset (Blasphemy, Ethnic Hatred, Ethnic Group Hatred, Undetermined, Non-Hatred)


## Data Description

This paper introduces hatebnBERT, a BERT-based model tailored to Bangla for religious hate speech detection. It creates two datasets: a binary classification dataset (hate/not) and a five-class categorization dataset (Blasphemy, Ethnic Hatred, Ethnic Group Hatred, Undetermined, Non-Hatred). The model achieves 98.8% accuracy on binary classification and 98.6% on multiclass classification, addressing Bangla-specific religious sensitivity between Muslim and Hindu communities.
