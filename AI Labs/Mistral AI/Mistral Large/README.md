# Mistral Large

## Overview
Closed-weight flagship model designed for high-end reasoning tasks and multilingual support. First model with function calling capabilities.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 1.0
- **Context Window:** 32k tokens
- **License:** Commercial (API access)
