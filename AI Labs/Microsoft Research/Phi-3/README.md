# Phi-3

## Overview
Family of highly capable small language models (SLMs) ranging from 3.8B to 14B parameters, designed to run locally on phones while maintaining strong reasoning and language understanding capabilities.

## Technical Specifications
- **Release Year:** 2024 (April)
- **Variants:** mini (3.8B) / small (7B) / medium (14B)
- **Context Length:** Up to 128K tokens
- **Training:** Scaled-up version of Phi-2 dataset

## Models
- **Phi-3-mini:** 3.8B parameters, optimized for mobile deployment
- **Phi-3-small:** 7B parameters, balanced performance and efficiency
- **Phi-3-medium:** 14B parameters, highest capability in the family
