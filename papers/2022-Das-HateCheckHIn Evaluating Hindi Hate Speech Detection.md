## Abstract

Extends HATECHECK functional test suite for hate speech detection models from English to Hindi. Functional test suite adapted for Hindi hate speech detection evaluation.

## Benchmark

**Name:** HateCheckHIn

## Data Description

HateCheckHIn functional test suite of 5.8K test cases for evaluating Hindi hate speech detection models, extending English HATECHECK with six new multilingual functionalities for code-mixed content.
