# Claude 2.1

## Overview
Doubled context window to 200k tokens and significant reductions in hallucination. First model to support tool use (beta).

## Technical Specifications
- **Release Year:** 2023 (November)
- **Version:** 2.1
- **Context Window:** 200k tokens
- **Model ID:** `claude-2.1`
- **Hallucination Rate:** 2x reduction compared to Claude 2.0
