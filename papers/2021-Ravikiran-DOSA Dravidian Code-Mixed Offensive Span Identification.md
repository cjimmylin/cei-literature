## Abstract

Offensive span identification dataset for Tamil-English (4786 comments, 6202 spans) and Kannada-English (1097 comments, 1641 spans) code-mixed text from YouTube. Provides rationale-based annotations for offensive content. Provides fine-grained offensive span annotations for Tamil and Kannada code-mixed text. Important for explainable hate speech detection research.

## Benchmark

**Name:** DOSA

## Data Description

DOSA dataset for offensive span identification in Tamil-English (4,786 comments, 6,202 spans) and Kannada-English (1,097 comments, 1,641 spans) code-mixed text from YouTube.
