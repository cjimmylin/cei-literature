## Abstract

The paper introduces intrinsic reward functions that explicitly encode core human values for automated Reinforcement Learning-based fine-tuning of foundation agent models. As an initial implementation, the paper evaluates training using the traditional philosophical frameworks of Deontological Ethics and Utilitarianism, quantifying moral rewards for agents in terms of actions and consequences on the Iterated Prisoner's Dilemma environment.

## Data Description

This is a shortened workshop version of the ICLR 2025 paper on moral alignment for LLM agents. It uses Gemma2-2b-it fine-tuned with PPO-based reinforcement learning on the Iterated Prisoner's Dilemma (IPD) with Deontological and Utilitarian intrinsic moral rewards. The study evaluates the agent's learned moral strategies and their generalization to four other matrix game environments using new action tokens at test time.
