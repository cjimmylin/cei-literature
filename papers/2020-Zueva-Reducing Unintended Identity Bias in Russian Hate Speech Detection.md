## Abstract

Proposes techniques for reducing unintended bias in Russian hate speech detection, including generating training data with language models using protected identity terms as context and applying word dropout.

## Data Description

A manually collected corpus of 100,000 Russian social media comments labeled for hate speech, plus generated data using a pre-trained Transformer language model (ruGPT2) for bias reduction.
