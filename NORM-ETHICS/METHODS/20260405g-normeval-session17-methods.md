# Methods: NormEval Dashboard Deployment and Figure Verification

**Date:** 2026-04-05
**Project:** `CEI-Lit-WS/NORM-ETHICS/`

## Data and Materials

Three static HTML/JavaScript dashboards deployed via GitHub Pages, each consisting of `index.html`, `app.js`, `data.js`, `charts.js`, `style.css`, and `data_cross_vendor.js`. The dashboards visualize meta-evaluation results for 54 normative ethics benchmarks scored across 41 features (26 v1 + 15 v2).

Two supplementary figures (PNG format) generated by matplotlib: Figure S1 (PCA benchmark clustering) and Figure S2 (temporal trends in benchmark properties).

## Procedure

### Dashboard Deployment

1. **Identified discrepancy:** The three deployed dashboards on GitHub Pages contained stale feature counts (46, 44, 18, 20) that had been corrected in local source files during Session 16 but never pushed to the deployment repositories.

2. **Cloned deployment repositories:** Each dashboard is hosted in a separate public GitHub repository (`cjimmylin/cei-normeval-dashboard`, `-v2`, `-v3`). Repositories were cloned to `/tmp/` for modification.

3. **Diffed local sources against deployed versions:** Used `grep` to identify all stale count references in deployed `index.html`, `app.js`, and `data.js`. Confirmed local DASHBOARD/ and DASHBOARD-v2/ sources contained the corrected values (41, 26+15, 15).

4. **Verified v2/v3 file identity:** Compared file lists and content between local DASHBOARD-v2/ and deployed v3 repository. Found content-identical files except for the count values and a `fonts/` directory unique to v3. This allowed copying corrected v2 source files to all three deployment targets.

5. **Deployed:** Copied corrected source files, committed with descriptive messages, and pushed to `main` branch of each repository. GitHub Pages builds confirmed in-progress via `gh run list`.

### Figure Verification

1. **Visual inspection:** Read both supplementary figure PNGs to check for stale "18 v2 features" labels in axis titles, legends, or annotations.
2. **Finding:** Neither figure references feature counts. S1 shows a PCA scatter plot (PC1 vs PC2 axes); S2 shows three temporal trend panels (ND, PE, CI vs Year).

## Computational Environment

- Git 2.x, GitHub CLI (`gh`)
- GitHub Pages static site hosting (automatic build on push to `main`)
- macOS Darwin 25.3.0

## Limitations and Decisions

- **v2 deployment gap:** The v2 deployed repository was 3 sessions behind (Session 12 → Session 17). The deployment included not just count fixes but all intervening improvements (Tab 11 feature reference table, council analysis expansions, style updates). These changes were reviewed via `git diff --stat` before pushing.
- **No DASHBOARD-v3 local source:** The v3 dashboard has no separate local source directory; it was originally created by copying v2 to the v3 repo with the addition of self-hosted fonts. Future corrections must either be applied directly to the cloned v3 repo or a DASHBOARD-v3/ local source should be established.
