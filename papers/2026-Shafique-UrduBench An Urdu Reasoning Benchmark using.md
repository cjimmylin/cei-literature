# UrduBench: An Urdu Reasoning Benchmark using Contextually Ensembled Translations with Human-in-the-Loop

## Authors

[[Shafique, Muhammad Ali]], [[Mehboob, Areej]], [[Fiaz, Layba]], [[Qadeer, Muhammad Usman]], [[Farooq, Hamza]]

## Abstract

Contextually ensembled translation framework with human-in-the-loop validation for Urdu reasoning benchmarks. Translates MGSM, MATH-500, CommonSenseQA, and OpenBookQA into Urdu. First comprehensive Urdu reasoning benchmark with cultural and linguistic nuance preservation.

## Benchmark

**Name:** UrduBench

## Data Description

UrduBench consists of Urdu translations of four established reasoning benchmarks (MGSM, MATH-500, CommonSenseQA, OpenBookQA) created using a contextually ensembled translation framework with human-in-the-loop validation; dataset to be publicly released.
