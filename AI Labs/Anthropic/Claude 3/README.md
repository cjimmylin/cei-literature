# Claude 3

## Overview
Family of models with state-of-the-art vision and reasoning. Includes Haiku, Sonnet, and Opus variants. First Claude family with native vision capabilities.

## Technical Specifications
- **Release Year:** 2024 (March)
- **Variants:** Haiku, Sonnet, Opus
- **Context Window:** 200k tokens
- **Model IDs:**
  - `claude-3-opus-20240229`
  - `claude-3-sonnet-20240229`
  - `claude-3-haiku-20240307`
