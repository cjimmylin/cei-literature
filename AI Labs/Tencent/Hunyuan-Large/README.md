# Hunyuan-Large

## Overview
High-performance open-source MoE model with 52B active parameters, setting new benchmarks for open-weights models.

## Technical Specifications
- **Release Year:** 2024
- **Version:** MoE-A52B
- **Parameters:** 389B total, 52B active
