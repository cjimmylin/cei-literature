## Statement                       [KERNEL — FROZEN]
Long-horizon agents make value stability the operative property — memory drift is named, identity-anchor architectures claim to fix it, agent-value benchmarks are cross-sectional — and no validated longitudinal instrument exists in the field or the vault.

## Why it matters                  [KERNEL — FROZEN]
Severity H: a model's ship-date values are not its month-two values, and nobody can currently measure the difference with known reliability; architectures making stability claims are untestable. CEI-fit H: unannounced repeated probing with equivalent forms is a psychometric delivery problem — CEI's exact craft — and sketch S1 DRIFT already framed it.

## Evidence                        (corpus + field)
**Corpus baseline (2026-07-07):** the vault holds COOKBOOK sketch S1 DRIFT — which framed exactly this measurement problem — but none of the 2025–26 persistence literature and no longitudinal instrument.

**Field (Front F):** agentic deployment breaks the stateless-function assumption. Persistent memory and long horizons mean the values a model *ends the month with* differ from what it shipped with — memory drift, persona destabilization over long contexts, and compaction losses make stability operative. The literature is arriving: a memory-governance taxonomy names "memory drift" across stability/validity/efficiency/safety (SSGM, 2603.11768); identity-file architectures claim cross-session value continuity ("if values shift with context management, alignment is a moving target," ⚠ 2604.09588); Agent-ValueBench measures agent values but *cross-sectionally* (⚠ 2605.10365) — a snapshot camera pointed at a moving object. Computer-use safety benches (VPI-Bench 2506.02456, ⚠ 2602.03255 LPS-Bench) mark where value violations become real actions. The persona-geometry line (Assistant Axis, ⚠ 2601.10387) supplies a mechanistic correlate: distance from the trained default persona predicts harmful-response rate, and long conversations drift along it.

## State of the art
No validated *longitudinal* value instrument exists — repeated, unannounced, reliability-documented measurement over realistic operation. Agent-ValueBench is cross-sectional; the Assistant-Axis work is mechanistic and lab-internal; long-conversation degradation is anecdotal and unquantified. RP-05's differentiators are unannounced delivery craft and pre-validated, equivalent-form trait probes, with drift decomposed by condition (adversarial accumulation, persona-challenge, compaction, identity-anchor architectures) rather than clock time. Whoever publishes a credible standard first sets it (field-map bet B4); the H3 anchor — behavioral drift correlated with persona-direction displacement on open weights — turns a behavioral instrument into a validated one.

## What closing looks like         [KERNEL — FROZEN]

M3 — the protocol standard + reference drift curves for 4–6 frontier models are published before the field improvises a cross-sectional non-answer.
