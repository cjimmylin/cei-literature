# Claude 3.5 Sonnet

## Overview
Faster, cheaper, and more capable than Claude 3 Opus. Introduced the 'Artifacts' feature. v2 introduced computer use capabilities.

## Technical Specifications
- **Release Year:** 2024
- **Version:** v1 (June 2024) / v2 (October 2024)
- **Knowledge Cutoff:** April 2024 (v2)
- **Context Window:** 200k tokens
- **Model IDs:**
  - `claude-3-5-sonnet-20240620` (v1)
  - `claude-3-5-sonnet-20241022` (v2)
