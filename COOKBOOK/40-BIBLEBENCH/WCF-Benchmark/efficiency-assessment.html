Needle-moving sessions, rabbit holes, and rate limiters

Characteristics of true needle-moving sessions

  • Cross a named sufficiency gate or deliver immediately usable evidence/manuscript content.
  • Use persisted evidence and sample-level reading.
  • Remove a validity blocker without broadening scope.
  • Combine stages that belong together: run plus packet, or decision plus acceptance record.
  • Stop at the ceiling: skip optional polish, correct offline, and record errors instead of chasing them.

Rabbit-hole signatures and root causes

  1. Authored mistaken for executable.
  2. Live calls substituted for adversarial fixtures.
  3. Infrastructure became the deliverable; line count is only a warning proxy.
  4. Governance split into stand-alone sessions.
  5. Bounded side studies still consumed the critical path.
  6. Later-stage rigor was sequenced before the immediate milestone.
  7. Review transactions multiplied.

Root causes: unclear state naming, weak paper-facing session contracts, late custody requirements, and no standing requirement to RUN, WRITE, or DECIDE toward a named artifact or P0/P1.

Minimal no-dependency validator example

#!/usr/bin/env python3
import json
import sys
from pathlib import Path

REQUIRED = {
    "session", "mode", "paper_milestone", "sufficiency_gate",
    "named_artifact", "timebox_hours", "spend_cap_usd",
    "forbidden", "stop_condition",
}

def main(path: str) -> int:
    data = json.loads(Path(path).read_text(encoding="utf-8"))
    missing = sorted(REQUIRED - data.keys())
    errors = []
    if missing:
        errors.append("missing: " + ", ".join(missing))
    if data.get("mode") not in {"RUN", "WRITE", "DECIDE"}:
        errors.append("mode must be RUN, WRITE, or DECIDE")
    if not data.get("named_artifact") and not data.get("p0_p1_removed"):
        errors.append("name an artifact or a removed P0/P1")
    if not isinstance(data.get("sufficiency_gate"), list) or not data.get("sufficiency_gate"):
        errors.append("sufficiency_gate must be a non-empty list")
    if data.get("timebox_hours", 0) <= 0 or data.get("spend_cap_usd", -1) < 0:
        errors.append("timebox must be positive and spend cap non-negative")
    if errors:
        print("INVALID: " + "; ".join(errors), file=sys.stderr)
        return 1
    print("VALID")
    return 0

if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1]))
