## Abstract

Hebrew NLI evaluation dataset with 8,325 context-hypothesis pairs requiring coreferential, temporal, logical and analytical reasoning. LLMs like DictaLM-2.0 and GPT-4o achieve max 60.12% vs human performance of ~87%. Tests Hebrew cultural-linguistic reasoning.

## Data Description

LCHAIM is a Hebrew NLI dataset of 8,325 context-hypothesis pairs translated and validated from the English ConTRoL dataset, requiring coreferential, temporal, logical, and analytical reasoning; released on GitHub.
