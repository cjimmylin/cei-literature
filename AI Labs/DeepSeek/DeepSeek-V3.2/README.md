# DeepSeek-V3.2

## Overview
Refined reasoning-first scaling of the V3 architecture, featuring DeepSeek Sparse Attention (DSA) for efficient long-context scenarios, a scalable RL framework, and a large-scale agentic task synthesis pipeline for tool-use and reasoning integration. Comparable to GPT-5 level performance.

## Technical Specifications
- **Release Year:** 2025
- **Version:** 3.2
- **Parameters:** 685B
- **Base Model:** DeepSeek-V3.2-Exp-Base
- **Key Features:**
  - DeepSeek Sparse Attention (DSA)
  - Scalable Reinforcement Learning Framework
  - Large-Scale Agentic Task Synthesis Pipeline
- **License:** MIT
