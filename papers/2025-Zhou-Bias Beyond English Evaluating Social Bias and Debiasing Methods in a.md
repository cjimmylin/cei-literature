# Bias Beyond English: Evaluating Social Bias and Debiasing Methods in a Low-Resource Setting

## Authors

[[Zhou, Ej]], [[Lu, Weiming]]

## Metadata

**Authors:** Ej Zhou; Weiming Lu

**Year:** 2025

**Type:** preprint

**Languages:** Indonesian

## Links

- **arXiv:** https://arxiv.org/abs/2504.11183

## Abstract

Multilingual bias evaluation dataset with Indonesian as a low-resource language. Four bias types: gender, race-color, nationality, religion. Demonstrates cross-lingual debiasing transfer from high-resource languages.

## Data Description

Multilingual bias evaluation datasets constructed for five languages (English, Chinese, Russian, Indonesian, Thai) covering four bias dimensions (gender, race-color, nationality, religion), enabling cross-lingual debiasing comparison in a low-resource setting.

**Source:** Language-Organized Benchmark Search (20260213), Agent A6
**Relevance:** Directly evaluates social biases in Indonesian language models across culturally relevant dimensions including religion and nationality.
