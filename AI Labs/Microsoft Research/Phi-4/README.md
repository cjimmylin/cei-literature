# Phi-4

## Overview
Next-generation Phi family with 14B parameter flagship model and specialized variants for reasoning, multimodal understanding, and compact deployment.

## Technical Specifications
- **Release Year:** 2024-2025
- **Flagship Model:** 14B parameters
- **Variants:** Phi-4, Phi-4-mini (3.8B), Phi-4-reasoning (14B), Phi-4-multimodal

## Models
- **Phi-4:** 14B parameter base model with focus on data quality
- **Phi-4-mini:** 3.8B parameter compact model with multimodal capabilities via Mixture-of-LoRAs
- **Phi-4-reasoning:** 14B parameter model fine-tuned on reasoning demonstrations from o3-mini
- **Phi-4-multimodal:** Lightweight multimodal foundation model processing text, image, and audio

## Performance Highlights
- Phi-4 achieves state-of-the-art performance for its size on reasoning benchmarks
- Phi-4-reasoning trained on "teachable" prompts generated by o3-mini
- Strong performance on LiveCodeBench and Codeforces coding benchmarks
