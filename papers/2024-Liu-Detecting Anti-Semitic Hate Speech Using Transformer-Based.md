# Detecting Anti-Semitic Hate Speech Using Transformer-Based Large Language Models

## Authors

[[Dengyi Liu]], [[Minghao Wang]], [[Andrew G. Catlin]]

## Metadata

**Authors:** Dengyi Liu, Minghao Wang, Andrew G. Catlin

**Year:** 2024

**Type:** preprint

**Venue:** arXiv

## Links

- **arXiv:** https://arxiv.org/abs/2405.03794

## Abstract

Fine-tunes transformer-based LLMs for antisemitism detection using a dataset of approximately 22K annotated samples. Achieves 80% accuracy and 72% F-Score in extracting antisemitic terms using NLP techniques including POS tagging, TF-IDF, and fine-tuned LLMs. Addresses the gap in machine learning approaches to antisemitism compared to other forms of online abuse.

## Dataset Information

Fine-tuned on ~22K annotated samples


## Data Description

Annotated dataset of approximately 3,000 Twitter posts labeled for anti-Semitic hate speech content using a threshold-based multi-annotator labeling process.
