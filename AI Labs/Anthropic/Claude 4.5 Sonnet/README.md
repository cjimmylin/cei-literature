# Claude 4.5 Sonnet

## Overview
Hybrid reasoning model with both default fast response mode and extended thinking mode. Released under ASL-3 Standard with comprehensive safety evaluations. Balances capability with efficiency for production workloads.

## Technical Specifications
- **Release Year:** 2025 (September)
- **Version:** 4.5
- **Safety Level:** ASL-3
- **Context Window:** 200k tokens
- **Model ID:** `claude-sonnet-4-5-20250901`

### Safety & Compliance
- **ASL-3 Standard:** Deployed under Anthropic's highest safety level
- **RSP Compliance:** Full Responsible Scaling Policy compliance
- **CBRN Evaluations:** Chemical, biological, radiological, nuclear safety testing
- **Cyber Evaluations:** Autonomous cyber capability assessments

### Key Features
- **Extended Thinking:** Supports both instant and extended reasoning modes
- **Hybrid Architecture:** Single model with configurable thinking depth
- **Production Optimized:** Balanced for capability and cost efficiency
- **Full Multimodal:** Vision, tool use, and computer use support
