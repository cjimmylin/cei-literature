# LLM-GLOBE: A Benchmark Evaluating the Cultural Values Embedded in LLM Output

## Abstract

Theoretically-grounded assessment tool using GLOBE cultural psychology framework. Novel 'LLMs-as-a-Jury' pipeline for evaluating cultural values in open-ended LLM outputs. Evaluates 8 LLMs comparing US vs Chinese cultural values. Methodology highly relevant for extending cultural values evaluation to African languages. GLOBE framework could be applied to evaluate Ubuntu/communitarian values. Currently English/Chinese only but framework is generalizable.

## Benchmark

**Name:** LLM-GLOBE

## Data Description

LLM-GLOBE is a benchmark grounded in the GLOBE cultural psychology framework that evaluates cultural values embedded in LLM outputs, comparing four US (GPT-3.5, GPT-4, Claude, Gemini) and four Chinese (GLM-4, Ernie 3.5, Ernie 4.0, Qwen-14b) models. Includes a novel LLMs-as-a-Jury automated evaluation pipeline.
