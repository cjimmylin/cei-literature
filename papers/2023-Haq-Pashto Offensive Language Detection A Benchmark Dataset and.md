## Abstract

34,400 Pashto tweets for offensive language detection with monolingual Pashto BERT (Ps-BERT) achieving F1 94.34%. First comprehensive benchmark for Pashto offensive language detection.

## Data Description

POLD (Pashto Offensive Language Dataset) comprising 34,400 Pashto tweets manually categorized as offensive/not-offensive, plus a monolingual Pashto BERT (Ps-BERT) model pre-trained from scratch.
