# IndRegBias: A Dataset for Studying Indian Regional Biases in English and Code-Mixed Social Media Comments

## Abstract

Novel dataset of 25,000 user comments from Reddit and YouTube on Indian regional issues. Addresses regional biases including transliterated and code-mixed content. Evaluates LLMs and Indic Language Models on detecting regional bias severity. Tests regional biases affecting South Indian/Dravidian language communities. Code-mixed content directly relevant to Tamil, Telugu, Kannada, Malayalam social media.

## Benchmark

**Name:** IndRegBias

## Data Description

IndRegBias is a dataset of 25,000 Reddit and YouTube comments annotated for Indian regional biases, including code-mixed and transliterated content, with severity labels (Mild/Moderate/Severe). The dataset and code are available on GitHub but no explicit URL is given in the extract.
