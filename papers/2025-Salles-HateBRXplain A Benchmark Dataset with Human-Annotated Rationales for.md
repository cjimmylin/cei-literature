## Abstract

First benchmark dataset for hate speech detection in Brazilian Portuguese with human-annotated text span rationales. Evaluated using mBERT, BERTimbau, DistilBERTimbau, and PTT5 models for explainability using LIME and SHAP.

## Data Description

HateBRXplain: first benchmark dataset for explainable hate speech detection in Brazilian Portuguese with human-annotated text span rationales (token-level), enabling evaluation of explainability methods (LIME, SHAP) for hate speech classifiers.
