# ChatGLM2-6B

## Overview
Second generation of the ChatGLM-6B series with significant performance boosts and a larger 32k context window.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 2.0
- **Parameters:** 6B
- **Context Window:** 32k
