## Abstract

First benchmark dataset for detecting hate speech in Malay with 4,892 annotated tweets. Proposes XLCaps two-channel deep learning model combining XLNet/capsule network with FastText/Bi-GRU for noisy Malay language posts.

## Data Description

First benchmark dataset of 4,892 annotated Malay tweets for hate speech detection, with multi-class labels, plus the XLCaps two-channel deep learning model combining XLNet/capsule network with FastText/Bi-GRU.
