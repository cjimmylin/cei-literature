## Abstract

Proposes adversarial alignment framework with Attacker/Actor/Critic for value consistency. Constructs bilingual Chinese-English evaluation dataset covering sovereignty, human rights, religion, politics, and ethnicity sensitive domains.

## Data Description

A bilingual (Chinese-English) value alignment evaluation benchmark covering 5 sensitive domains (Sovereignty, Human Rights, Religion, Politics, Ethnicity) with 31 subcategories, plus an adversarial alignment training dataset of 64,238 query-response pairs; both released at the GitHub repository.
