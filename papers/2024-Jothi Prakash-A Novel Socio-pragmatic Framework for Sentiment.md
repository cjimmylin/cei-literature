## Abstract

Socio-pragmatic framework for sentiment analysis in Dravidian code-switched texts using XLM-RoBERTa with socio-pragmatic insights. Achieved 72.3% accuracy, 72.5% F1-score on Dravidian Code-Mixed Dataset. Culturally grounded sentiment analysis for Dravidian languages. Socio-pragmatic approach captures cultural nuances in code-switched text.

## Benchmark

**Name:** MultiSwitchNet

## Data Description

This paper presents a socio-pragmatic framework for sentiment analysis in Dravidian-English code-switched texts. It evaluates XLM-RoBERTa with socio-pragmatic insights on the Dravidian Code-Mixed Dataset, achieving 72.3% accuracy and 72.5% F1-score. The approach captures cultural nuances in code-switched text from Dravidian languages.
