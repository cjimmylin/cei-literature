## Abstract

Multilingual PLM for 23 African languages using novel self-active learning. Outperforms AfriBERTa, mBERT, XLMR-base on NER and sentiment analysis despite 14x smaller training data. Evaluated on MasakhaNER 1.0 and 2.0. Covers multiple target languages. African-centric language model enabling better NLP for African languages. Evaluated on sentiment analysis which captures cultural values expression.

## Benchmark

**Name:** AfroLM

## Data Description

AfroLM pretrained language model for 23 African languages using self-active learning framework. Releases code and pretraining configuration.
