# ViToSA: Audio-Based Toxic Spans Detection on Vietnamese Speech Utterances

## Authors

[[Van-Phu Quang Do]], [[Duc-Ung To]], [[Son T. Luu]], [[Kiet Van Nguyen]]

## Links

- **arXiv:** https://arxiv.org/abs/2506.00636

## Abstract

First benchmark for toxic spans detection in Vietnamese speech. 11,000 audio samples (25 hours) with human-annotated transcripts. Addresses gap in audio-based toxicity detection for low-resource Vietnamese.

## Data Description

Introduces VITOSA, the first dataset for toxic spans detection in Vietnamese speech, comprising 11,802 audio-transcript pairs (24.75 hours) with human-annotated toxic span labels. Released on HuggingFace for ASR and toxic spans detection research.
