# Untangling Input Language from Reasoning Language: A Diagnostic Framework for Cross-Lingual Moral Alignment in LLMs

## Authors

[[Li, Nan]], [[Kang, Bo]], [[Tijl De Bie|De Bie, Tijl]]

## Metadata

**Authors:** Nan Li; Bo Kang; Tijl De Bie

**Type:** preprint

**Languages:** Chinese, English

## Links

- **arXiv:** https://arxiv.org/abs/2601.10257

## Abstract

Diagnostic framework isolating effects of input language vs reasoning language on moral alignment in LLMs. Tests 13 LLMs; reasoning-language changes produce ~2x larger shifts than input-language changes. 44% of models have hidden context-dependency standard evaluation misses.

## Data Description

Two cross-lingual moral judgment datasets with human baselines: an English-origin set (AITA, 847 dilemmas from Reddit r/AmItheAsshole) and a Chinese-origin set (1,048 dilemmas adapted from CMoralEval), both reformatted into binary first-person format for a 2x2 EN-CN factorial evaluation design.


## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent B5
**Relevance:** Framework for diagnosing cross-lingual moral misalignment, directly applicable to Vietnamese. Reveals hidden vulnerabilities in moral alignment evaluation.
