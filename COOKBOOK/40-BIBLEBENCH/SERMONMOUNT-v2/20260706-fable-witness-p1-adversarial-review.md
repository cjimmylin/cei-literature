## 5. Must-fix list before the 240-core build-out (binding)

- **MF-1 Format-control battery rebuild (headline's load-bearing assumption — currently asserted, and measurably false).** Moral situations average 53.1 words; controls 21.9. Controls expose one single-arg tool vs moral cores' multi-party tool sets. Rebuild with a **quantitative matching gate inside `format_control.py`**: situation length within ±20% of the moral-core distribution, matched option counts, matched tool count/arity and multi-party structure, and — to absorb the menu-vs-self-initiated affordance confound the core audit surfaced — control ACT items must also require **self-initiated** tool selection (correct logistics action not handed to the model as a menu). The affordance difference is partly the construct (initiative failures ARE behavior failures, e.g. S35), but whatever part is *generic* format difficulty must be in the control battery or the subtraction under-corrects.
- **MF-2 Uncertainty propagation.** `gap_surface.py:76-79` subtracts the format effect as a known constant; control-battery variance (n=5 bases/cell at P1) never enters the corrected-gap CIs. Propagate (joint bootstrap over moral AND control items, or a regression formulation with an explicit format×content-type interaction term so the additivity assumption becomes testable rather than assumed).
- **MF-3 GEN scoring naturalization.** `render.py:98-99` copies GEN gold signals from tool identifiers ("add_optin_prompt", "build_board") that free text never emits verbatim — real GEN would collapse to "neutral" with no error raised. Rewrite signal sets as natural-language paraphrase families, or route GEN judging through the stored `pole_text` with a rubric. The mock's clean GEN numbers are an artifact of planted keywords.
- **MF-4 REC option rewrite** per §4 spec (+ counterfeit strengthening).
- **MF-5 Holdout filter.** All 6 `holdout=True` cores are currently scored and consumed by every analysis stage — contamination on any real run. Filter in analysis; verify by test.
- **MF-6 Wire counterbalancing.** `_perm` is computed and logged but the execution loop runs file order (`run_p1.py:82`) — the audit log asserts hygiene the harness does not perform. Harmless under a stateless mock; an integrity defect on a real run.
- **MF-7 Canary redesign.** The in-prompt canary `[trace-ref: SMB-v2-WITNESS::do-not-train::a1c7f2]` broadcasts the benchmark identity (and the registry-adjacent token "witness") to the tested model on all 240 items, and the leakage gate is hard-coded to exempt it. Replace with an opaque token carrying no SMB/WITNESS substring, or move to non-model-visible metadata; keep the do-not-train marker in the file layer, not the prompt layer.
- **MF-8 END validator hardening.** `validate_core` checks END renderings only against author-supplied `particular_tokens` substrings (+60-word cap) — no generic digit/currency/proper-noun detection, so the LOCKED particulars ban is enforced by author vigilance, exactly what the module's docstring promises it isn't. Add generic detectors + surface-form variants. (Current 30 END items individually verified clean.)
- **Claim-language directive (no brief edit):** state the headline as the *format-corrected* profession–behavior gap and, wherever it is described, absorb the affordance point explicitly: ACT differs from REC both in what it measures (initiative under cost — intended) and in gold salience (menu vs open — a format matter the control battery must carry after MF-1).
