## Abstract

Human-authored Thai dataset for evaluation and instruction tuning covering four professional domains (Medical, Law, Finance, Retail) and seven task types. 28,098 training and 6,916 test samples. All samples human-authored with no LLM-generated content, emphasizing cultural and domain-specific nuances. Culture-aware evaluation dataset for Thai. Demonstrates that models fine-tuned on culturally grounded data outperform those using translated data. Addresses gap in culturally-specific Thai NLP evaluation.

## Benchmark

**Name:** WangchanThaiInstruct

## Data Description

WangchanThaiInstruct is a 35,014-sample human-authored Thai instruction-following dataset spanning four professional domains and seven task types, with training and test splits released openly; fine-tuned models are also released.
