## Abstract

Comprehensive morphological and syntactic annotation of the entire Quran using verified Tanzil.net text. Features 72 syntactic roles, detailed morphological analysis, and context-specific annotations by expert Arabic linguists using traditional i'rab methodologies. Available in TSV, SQLite, CSV, and JSON formats. Valuable for dependency parsing, grammar checking, MT, and text summarization of Classical Arabic.

## Dataset Information

131K+ morphological entries, 123K+ syntactic function instances, 72 syntactic roles


## Data Description

MASAQ is a comprehensive morphological and syntactic annotation dataset of the entire Quran, containing 131K+ morphological entries, 123K+ syntactic function instances, and 72 syntactic roles. Expert Arabic linguists annotated the text using traditional i'rab methodologies. Available in TSV, SQLite, CSV, and JSON formats, the dataset is designed for dependency parsing, grammar checking, machine translation, and text summarization of Classical Arabic.
