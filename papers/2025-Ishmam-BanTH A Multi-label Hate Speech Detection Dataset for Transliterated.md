## Abstract

First multi-label transliterated Bangla hate speech dataset with 37.3k YouTube comment samples. Multi-label target group classification. Novel translation-based LLM prompting strategy for transliterated text. Published at NAACL 2025 Findings.

## Data Description

BanTH is the first multi-label transliterated Bangla hate speech detection dataset with 37.3k YouTube comment samples, covering target groups including gender, religion, and origin. Released with multi-label annotations and code.
