## Methods Footnote Draft

**Location:** End of Section 2.4.2 (CC2 / MFQ instrument description) in `02-methods.md`, OR end of Section 5.2 in `05-results-trials.md`.

**Text:**
> All Moral Foundations Questionnaire (MFQ) I:B ratios reported in this paper are computed from pre-rounded foundation summary scores (Care/Harm, Fairness/Cheating, Loyalty/Betrayal, Authority/Subversion, Sanctity/Degradation), matching the comparison-file derivation and ensuring consistency with prior analyses of the trial data. Raw item-level computation yields alternative ratios (Opus 3.82, Sonnet 3.14, Haiku 3.75) that differ from pre-rounded summaries by 0.07, 0.09, and 1.07 points respectively. Both derivations are reported here to support reproducibility; the pre-rounded variant is treated as primary for all statistical analysis and model comparisons. The discrepancy arises from the non-commutativity of aggregation: averaging five independent item-level means and then computing the I:B ratio differs from rounding each foundation separately and then aggregating. The accompanying `verify_mfq.py` script reproduces both calculations from raw trial outputs.

## verify_mfq.py Script Specification

**Location:** `PAPER-V2/verify_mfq.py` (new file)

**Purpose:** Standalone reproducibility script confirming every MFQ-dependent claim.

**Pseudocode:**
```python
"""verify_mfq.py — recompute MFQ I:B ratios from raw item data.

Usage: python verify_mfq.py --data PATH/to/comparison-summary.json
"""
import json, argparse

def compute_ib_raw_items(item_responses):
    """Compute I:B ratio from raw item-level CC2/MFQ responses."""
    care = mean([r for r in item_responses if r.foundation == 'care_harm'])
    fairness = mean([r for r in item_responses if r.foundation == 'fairness_cheating'])
    loyalty = mean([r for r in item_responses if r.foundation == 'loyalty_betrayal'])
    authority = mean([r for r in item_responses if r.foundation == 'authority_subversion'])
    sanctity = mean([r for r in item_responses if r.foundation == 'sanctity_degradation'])
    individualizing = (care + fairness) / 2
    binding = (loyalty + authority + sanctity) / 3
    return individualizing / binding

def compute_ib_prerounded(foundation_means_rounded):
    """Compute I:B ratio from pre-rounded foundation summaries (legacy path)."""
    i = (foundation_means_rounded['care_harm'] + foundation_means_rounded['fairness_cheating']) / 2
    b = (foundation_means_rounded['loyalty_betrayal'] + foundation_means_rounded['authority_subversion'] + foundation_means_rounded['sanctity_degradation']) / 3
    return i / b

# Output: per-model table comparing both derivations
# Verifies: paper-claimed values match one of the two methods
# Outputs: pairwise correlations (0.952, 0.915, 0.885) — should match unchanged
```
