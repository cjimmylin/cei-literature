# Mistral Large 2

## Overview
Frontier-class model with 123B parameters, rivaling the performance of GPT-4o and Claude 3.5 Sonnet. Features native function calling, JSON output, and 80+ language support.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 24.07
- **Parameters:** 123B (dense)
- **Context Window:** 128k tokens
- **Languages:** 80+ natural languages, 80+ programming languages
- **License:** Mistral AI Research License (research/non-commercial)
- **Format:** Safetensors (BF16)
