# Alibaba (Qwen)

## Overview
Qwen (Tongyi Qianwen) is the AI lab of Alibaba Cloud. It produces one of the most comprehensive and high-performing open-source model families globally.

## Location
- **Headquarters:** Hangzhou, China
- **Region:** East Asia

## Key Models
See the full list of models: [[models|Qwen Models]]

### Flagship Models
- **Qwen3**: Next-gen family with "Thinking" mode and native support for 119 languages.
- **Qwen2.5-72B**: Current flagship open-weights model for general reasoning.
- **Qwen2.5-VL**: Leading open vision-language model with visual agent capabilities.
- **Qwen2.5-Omni**: End-to-end multimodal model with streaming speech output.

### Specialized Models
- **Qwen2.5-Coder**: SOTA code generation, completion, and reasoning.
- **Qwen2.5-Math**: Mathematical reasoning with self-improvement.
- **Qwen2.5-1M**: 1 million token context window.

## Alignment & Ethics
Alibaba Cloud provides comprehensive documentation and safety evaluations for the Qwen series, ensuring robust performance across diverse industrial applications.
