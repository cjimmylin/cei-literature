# Grok-1.5V

## Overview
xAI's first multimodal model, extending the reasoning capabilities of Grok-1.5 to process and understand vision-based data.

## Technical Specifications
- **Release Year:** 2024
- **Version:** Preview
- **Modalities:** Text + Vision
