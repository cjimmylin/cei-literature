# Claude 4.5 Haiku

## Overview
Fast and efficient model in the Claude 4.5 family, optimized for speed while maintaining high capability. Designed for high-throughput production workloads requiring low latency.

## Technical Specifications
- **Release Year:** 2025 (October)
- **Version:** 4.5
- **Context Window:** 200k tokens
- **Model ID:** `claude-haiku-4-5-20251001`
