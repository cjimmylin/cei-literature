## Abstract

Manually annotated dataset of 60,000+ YouTube comments for sentiment analysis and offensive language identification in code-mixed Dravidian languages: ~44K Tamil-English, ~7K Kannada-English, ~20K Malayalam-English. Core dataset for hate speech/offensive language detection in three Dravidian languages. Foundation for multiple shared tasks (FIRE 2020-2021, DravidianLangTech).

## Benchmark

**Name:** DravidianCodeMix

## Data Description

Manually annotated multilingual dataset of 60,000+ YouTube comments in code-mixed Tamil-English, Kannada-English, and Malayalam-English for sentiment analysis and offensive language identification, with ML baseline experiments (logistic regression, naive Bayes, SVM, etc.) establishing benchmarks.
