# DeepSeek-V2

## Overview
Large-scale Mixture-of-Experts (MoE) model featuring Multi-head Latent Attention (MLA) for efficient inference through low-rank key-value compression. Combines the DeepSeekMoE architecture with innovative attention mechanisms.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 2.0
- **Parameters:** 236B total, 21B active per token
- **Context Window:** 128K tokens
- **Architecture:** MoE with MLA (Multi-head Latent Attention)
- **Hardware Requirements:** 80GB x 8 GPUs (BF16 inference)
- **License:** MIT (code) + DeepSeek Model License (supports commercial use)
