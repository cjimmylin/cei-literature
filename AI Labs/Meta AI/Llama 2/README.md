# Llama 2

## Overview
Open foundation and fine-tuned chat models, widely adopted by the community and optimized for dialogue.

## Technical Specifications
- **Release Year:** 2023
- **Version:** 2.0
- **Parameters:** 7B, 13B, 70B
- **Context Window:** 4k tokens
- **Training Data:** 2 trillion tokens
