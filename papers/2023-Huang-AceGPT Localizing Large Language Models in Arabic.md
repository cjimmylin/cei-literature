## Abstract

Introduces AceGPT, an Arabic-localized LLM with RLAIF using reward model attuned to local culture and values. Introduces ACVA benchmark: 8,000+ binary true/false statements generated by GPT-3.5 Turbo covering 50 Arabic cultural topics including clothing, mindset, daily life, Islam influence. NAACL accepted.

## Data Description

ACVA (Arabic Cultural and Value Alignment) benchmark: 8,000+ binary true/false statements across 50 Arabic cultural topics, plus localized Arabic instruction-tuning data and preference data for RLAIF.
