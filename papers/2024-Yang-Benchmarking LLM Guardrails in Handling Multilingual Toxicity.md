## Abstract

Benchmarks state-of-the-art guardrails across 7 datasets and 10+ languages. Korean inputs found particularly vulnerable to bypassing guardrails. Existing guardrails ineffective at handling multilingual toxicity.

## Data Description

A comprehensive multilingual test suite spanning 7 existing datasets and 10+ languages for benchmarking guardrail models on multilingual toxicity detection and jailbreaking robustness.
