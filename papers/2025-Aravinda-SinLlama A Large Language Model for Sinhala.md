# SinLlama: A Large Language Model for Sinhala

## Authors

[[Aravinda, H. W. K]], [[Sirajudeen, Rashad]], [[Karunathilake, Samith]], [[de Silva, Nisansa]], [[Ranathunga, Surangika]], [[Kaur, Rishemjit]]

## Links

- **arXiv:** https://arxiv.org/abs/2508.09115

## Abstract

Extension of Llama-3-8B with enhanced Sinhala-specific tokenizer and continual pre-training on 10M sentence Sinhala corpus. First dedicated Sinhala LLM enabling downstream evaluation.

## Data Description

10.7 million Sinhala sentences combined from MADLAD-400 and CulturaX with heuristic filtering, released as the SinLlama pre-training corpus; SinLlama model also released at https://huggingface.co/polyglots/SinLlama_v01.
