# Claude 3.5 Haiku

## Overview
Extremely fast and efficient model, matching Claude 3 Opus performance in certain tasks. Optimized for speed and cost-efficiency while maintaining high capability.

## Technical Specifications
- **Release Year:** 2024 (October)
- **Version:** v1
- **Knowledge Cutoff:** July 2024
- **Context Window:** 200k tokens
- **Model ID:** `claude-3-5-haiku-20241022`
