# Megatron-Turing NLG

## Overview
A collaborative project between Microsoft and NVIDIA, resulting in a massive 530B parameter model trained using the DeepSpeed and Megatron frameworks.

## Technical Specifications
- **Release Year:** 2021
- **Version:** 530B
- **Parameters:** 530B
