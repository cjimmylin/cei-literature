# Fabricated Hadith Detection: A Novel Matn-Based Approach With Transformer Language Models (MAHADDAT)

## Authors

[[Kamel Gaanoun]], [[Mohammed Alsuhaibani]]

## Metadata

**Authors:** Kamel Gaanoun, Mohammed Alsuhaibani

**Year:** 2022

**Type:** preprint

**Venue:** IEEE Access

## Links

- **Code/Data:** MAHADDAT dataset (released with paper)

## Abstract

Creates MAHADDAT, the first dataset dedicated to fabricated (Mawdu) Hadith detection. Uses Matn (textual content) analysis rather than solely Sanad (narrator chain). BERT-based system achieves 92.47% F1 score. Foundational resource for Hadith authenticity verification using NLP.

## Benchmark

**Name:** MAHADDAT

## Dataset Information

MAHADDAT dataset (first dedicated Mawdu Hadith dataset; exact size in paper)


## Data Description

MAHADDAT: first dataset dedicated to fabricated (Mawdu) Hadith detection, plus NAH Plus corpus of non-authentic Hadiths. Evaluated with multiple Arabic BERT variants achieving 92.47% F1.
