## Abstract

Summary: Focuses on depth of translation within each language (multiple translations per language) rather than breadth across languages. Manually verified metadata with publication history for each translation. Addresses a gap in existing biblical corpora for intra-language translation comparison and analysis.

## Dataset Information

657 New Testament translations (352 unique) across 5 languages with deep coverage


## Data Description

Targum is a multilingual corpus of 657 New Testament translations (352 unique) across five languages (English, French, Italian, Polish, Spanish), with manually verified metadata; the public-domain subset and code will be released, with copyrighted texts available upon request.
