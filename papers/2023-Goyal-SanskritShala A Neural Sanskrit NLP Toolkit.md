## Abstract

> First neural-based Sanskrit NLP toolkit with web interface. Reports SOTA on word segmentation, morphological tagging, dependency parsing, and compound identification benchmarks. Releases 7 word embedding models for Sanskrit. Foundation for processing Hindu scriptural texts.

## Dataset Information

7 word embedding models + multiple annotated datasets (word similarity, relatedness, categorization, analogy)


## Data Description

SanskritShala toolkit releasing 7 pretrained Sanskrit word embedding models (Word2Vec, GloVe, fastText, charLM, ELMo, ALBERT, LCM) and 4 intrinsic evaluation datasets (word similarity, relatedness, categorization, analogy prediction) for Sanskrit NLP.
