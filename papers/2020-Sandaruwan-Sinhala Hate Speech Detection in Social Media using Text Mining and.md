## Abstract

Hate speech detection in Sinhala social media using text mining and ML. MNB with character tri-gram achieves 92.33% accuracy. Creates Sinhala hate speech dataset from social media comments.

## Data Description

A Sinhala-language hate speech dataset collected from social media comments, used to train and evaluate classifiers (best result: MNB with character tri-grams at 92.33% accuracy).
