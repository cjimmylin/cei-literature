## Abstract

Hybrid system for Turkish hate speech detection using ensemble deep learning with BERT and clustered-graph networks. Includes 2K dataset of Turkish tweets labeled for hate speech, aggressive expression, and neither. Achieves 87.81% F1-score. Novel Turkish hate speech detection system and dataset combining graph networks with transformers. Three-class annotation scheme provides nuanced categorization.

## Benchmark

**Name:** So-haTRed

## Data Description

So-haTRed is a hybrid system for Turkish hate speech detection using ensemble deep learning with BERT and clustered-graph networks. The paper includes a dataset of approximately 2,000 Turkish tweets labeled across three classes: hate speech, aggressive expression, and neither. The system achieves 87.81% F1-score. No LLMs were tested; the approach relies on BERT-based transformers and graph neural networks rather than generative LLMs.
