# Phi-2

## Overview
Phi-2 is a 2.7B parameter Transformer model that demonstrates extraordinary reasoning and language understanding capabilities, surpassing Mistral and Llama-2 models at 7B and 13B parameters on various benchmarks.

## Technical Specifications
- **Release Year:** 2023 (December)
- **Parameters:** 2.7B
- **Training:** 1.4T tokens from Synthetic and Web datasets for NLP and coding
- **Context Length:** 2048 tokens
- **Architecture:** Transformer with next-word prediction objective

## Performance
- Surpasses Mistral 7B and Llama-2 13B on various aggregated benchmarks
- Matches or outperforms Google Gemini Nano 2
- Strong multi-step reasoning on coding and math tasks
