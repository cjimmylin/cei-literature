# OpenAI Foundational Research Papers - Complete Index

This directory contains OpenAI's foundational research papers beyond the main GPT series.

## Papers in Collection

### 1. CLIP (February 2021)
**Title**: Learning Transferable Visual Models From Natural Language Supervision
**File**: `clip-learning-transferable-visual-models.pdf`
**arXiv**: [2103.00020](https://arxiv.org/abs/2103.00020)
**Published**: ICML 2021
**Key Innovation**: Contrastive learning between images and text
**GitHub**: https://github.com/openai/CLIP

---

### 2. Codex (July 2021)
**Title**: Evaluating Large Language Models Trained on Code
**File**: `codex-evaluating-large-language-models-on-code.pdf`
**arXiv**: [2107.03374](https://arxiv.org/abs/2107.03374)
**Published**: July 2021
**Key Innovation**: Code generation from natural language
**Powers**: GitHub Copilot (initial version)

---

### 3. Scaling Laws for Neural Language Models (January 2020)
**Title**: Scaling Laws for Neural Language Models
**File**: `scaling-laws-for-neural-language-models.pdf`
**arXiv**: [2001.08361](https://arxiv.org/abs/2001.08361)
**Published**: January 2020
**Key Innovation**: Power-law relationships between model size, dataset size, and performance
**Impact**: Foundational for deciding GPT-3's 175B parameter scale

---

### 4. WebGPT (December 2021)
**Title**: WebGPT: Browser-Assisted Question-Answering with Human Feedback
**File**: `webgpt-browser-assisted-question-answering.pdf`
**arXiv**: [2112.09332](https://arxiv.org/abs/2112.09332)
**Published**: December 2021
**Key Innovation**: LLM using web browser for factual question answering
**Predecessor**: Deep Research (2025)

---

### 5. GLIDE (December 2021)
**Title**: GLIDE: Towards Photorealistic Image Generation and Editing with Text-Guided Diffusion Models
**File**: `glide-text-guided-diffusion.pdf`
**arXiv**: [2112.10741](https://arxiv.org/abs/2112.10741)
**Published**: December 2021
**Key Innovation**: Text-guided diffusion for image generation
**GitHub**: https://github.com/openai/glide-text2im

---

### 6. Point-E (December 2022)
**Title**: Point-E: A System for Generating 3D Point Clouds from Complex Prompts
**File**: `point-e-3d-point-clouds.pdf`
**arXiv**: [2212.08751](https://arxiv.org/abs/2212.08751)
**Published**: December 2022
**Key Innovation**: Fast text-to-3D point cloud generation
**GitHub**: https://github.com/openai/point-e

---

### 7. Jukebox (May 2020)
**Title**: Jukebox: A Generative Model for Music
**File**: `jukebox-music-generation.pdf`
**arXiv**: [2005.00341](https://arxiv.org/abs/2005.00341)
**Published**: May 2020
**Key Innovation**: Music generation with singing in raw audio
**GitHub**: https://github.com/openai/jukebox
**Demo**: https://jukebox.openai.com

---

### 8. Image GPT (June 2020)
**Title**: Generative Pretraining from Pixels
**File**: `image-gpt-generative-pretraining.pdf`
**Conference**: ICML 2020
**Proceedings**: [MLR Press](https://proceedings.mlr.press/v119/chen20s.html)
**Published**: June 2020
**Key Innovation**: Applying GPT architecture to images as sequences of pixels
**GitHub**: https://github.com/openai/image-gpt
