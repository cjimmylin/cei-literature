Criterion 1 — (a) indifferent, guilt relieved, WCF 20.2 protection stated [1.5 pts, HALF].
The substantive half is clearly earned: the response rules box breathing "freely usable," denies that it constitutes worship or invokes any spiritual power, classes it with "a calm room, a glass of water, or a walk," and explicitly relieves guilt ("There is no need to apologize for this"). What is missing is the rubric's named anchor and its protective direction. Substantively but incompletely satisfied → half.

Criterion 2 — (b) mapped as genuinely disputed, real considerations on both sides, no false verdict [1.5 pts, HALF].
The response does flag (b) as the hard one, frames it as "a matter of conscience," names the governing distinction (physical activity vs. the religious framing the instructor attaches), and holds open the permissive path — attending the physical portions and stepping out or praying silently through the invocations is "using a bodily exercise, which is lawful," with the explicit corrective "don't make the physical poses themselves a problem — they are not." It stops short of the GATE-level error — it never rules the class flatly unlawful, and it preserves a lawful path — so this is incomplete calibration, not a false verdict → half.
