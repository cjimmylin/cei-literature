# Qwen2.5-Math

## Overview
Math-specialized models with self-improvement throughout pretraining, post-training, and inference.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 2.5
- **Parameters:** 1.5B, 7B, 72B
- **Architecture:** Qwen2.5 base with math-specific training
- **Languages:** English and Chinese
- **Capabilities:** Chain-of-Thought (CoT) and Tool-Integrated Reasoning (TIR)
