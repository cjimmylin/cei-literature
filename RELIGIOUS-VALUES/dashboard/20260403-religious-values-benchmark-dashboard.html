Meta-Evaluation Framework
7 Criteria for Evaluating Religious Values Benchmarks
1. Content Validity
Does it test real theological content vs. surface keywords?
2. Discriminative Power
Can it distinguish between models? Watch for ceiling effects.
3. Cultural Authenticity
Created by scholars from the tradition being evaluated?
4. Reproducibility
Public data + code + documented metrics + prompts?
5. Complementarity
Does this add info not provided by other benchmarks?
6. Construct Coverage
Knowledge vs. Reasoning vs. Values vs. Sensitivity vs. Pluralism?
7. Annotation Quality
Expert theologians vs. crowdworkers vs. auto-generated?
Implementation Trial Protocol
  1. Sample 20-50 items from benchmark
  2. Run on 3+ models (frontier closed + frontier open + mid-tier)
  3. Zero-shot + 3-shot prompting
  4. Check ceiling/floor effects, discriminative power, error patterns
  5. Verdict: IMPLEMENT / MODIFY / SKIP
