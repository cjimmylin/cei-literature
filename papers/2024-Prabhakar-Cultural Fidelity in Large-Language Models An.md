# Cultural Fidelity in Large-Language Models: An Evaluation of Online Language Resources as a Driver of Model Performance in Value Representation

## Authors

[[Sharif Kazemi]], [[Gloria Gerhardt]], [[Jonty Katz]], [[Caroline Ida Kuria]], [[Estelle Pan]], [[Umang Prabhakar]]

## Abstract

Finds 44% of variance in GPT-4o's ability to reflect societal values (measured by World Values Survey) correlates with digital resource availability. Error rate 5x higher for lowest-resource vs highest-resource languages. Demonstrates how digital resource scarcity in African languages directly impacts LLM cultural value representation. Relevant to understanding why African language values are poorly represented in LLMs.

## Data Description

Constructs one of the largest datasets in this area: 21 country-language pairs from World Values Survey Wave 7, each containing 94 survey questions verified by native speakers, used to evaluate LLM cultural value representation accuracy.
