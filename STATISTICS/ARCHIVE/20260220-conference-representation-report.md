## 9. Classification Methodology

The CONF-CC field was populated using a 3-phase waterfall classifier (`PYTHON/add_conference_field_cc.py`):

1. **Phase 1 (Local Heuristic):** Regex matching on `publication` and `type` YAML fields against 90+ known conference aliases and 50+ journal patterns. Instant.
2. **Phase 2 (OpenAlex API):** DOI-based lookup for papers unresolved by Phase 1. Returns venue name and type. ~0.1s per query.
3. **Phase 3 (Semantic Scholar API):** ArXiv ID or DOI lookup for remaining papers. Returns venue and publication year. ~4s per query.
4. **Fallback:** Papers with no API match classified as Preprint (if type=preprint) or N/A.

### Phase Attribution

| Phase | Papers | Description |
|-------|-------:|-------------|
| Phase 1 + 2 (pre-existing) | 1645 | Classified by local heuristic or OpenAlex before Phase 3 run |
| Phase 3 (Semantic Scholar) | 134 | Resolved via Semantic Scholar API |
| Fallback | 255 | Unresolved → Preprint or N/A based on paper type |
| **Total** | **2034** | |

### Report Categorization Logic

This report groups the 326 unique CONF-CC values into 6 categories:

```
CONF-CC == "Preprint"               → Preprint
CONF-CC == "N/A"                     → N/A
contains "Findings"                  → Findings
contains "Workshop"/"Demo"/"Shared"  → Workshop
matches KNOWN_JOURNALS set            → Journal
contains "Journal"/"Transactions"    → Journal (heuristic)
everything else                      → Conference
```

Journal detection uses 94 known journal names compiled from `JOURNAL_EXACT` (38 entries) and `JOURNAL_SUBSTRING` (19 entries) dictionaries in `add_conference_field_cc.py`, plus 51 additional journals identified from OpenAlex/Semantic Scholar API results.
