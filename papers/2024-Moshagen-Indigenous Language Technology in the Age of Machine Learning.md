## Abstract

Examines how very few Indigenous languages have the necessary amount of texts for making tools based on machine learning technology. When most language technology is based on LLMs, it risks most Indigenous language online text being produced by neural text generation, making online texts potentially untrustworthy as sources for authentic Indigenous languages. Addresses critical evaluation challenges for indigenous language AI.

## Data Description

This paper examines how very few Indigenous languages have sufficient text for building machine learning-based language tools. It raises the critical concern that when most language technology relies on LLMs, online text in Indigenous languages risks being predominantly generated by neural text generation, making these texts untrustworthy as authentic language sources. The paper does not create a dataset or benchmark.
