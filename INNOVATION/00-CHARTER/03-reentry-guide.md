# Re-entry Guide — How to Start a Session in INNOVATION

**Created:** 2026-07-07 · **Author:** Fable 5 · **Purpose:** minimum-context on-ramps by session type. Read this + your playbook; do not re-read the whole folder.

## Universal first three steps (every session type)

1. Read `../07-opus-handoff.md` — the live queue tells you what's next and what's blocked.
2. Read `04-decision-log.md` (last ~10 entries) — what changed since the docs were written.
3. Check `../PENDING-RULINGS.md` if it exists — you may be blocked, or you may be the adjudicator.

## Playbook A — Opus session, keys available

- Current priority: `07-opus-handoff.md` Cycle 2 (shared runner T1 → RP-07 HAWTHORNE → RP-04 phase 1).
- Before running anything live: confirm the runner logs full transcripts, has backoff, and that any FRUITBENCH-derived harness respects that project's live-mode gates.
- Read the target RP brief *in full* before its first task; kill criteria are binding (protocol §2). Fable-tier gates marked in the brief (e.g., HAWTHORNE's 20-pair sample review) → file a PR and pause that line if no adjudicator is available; sibling lines continue.
- End of session: check off completed handoff items, one line in the decision log.

## Playbook B — Opus session, credential-blocked

- Work Cycle-1 tasks only: taxonomy codes (V2, **before** acquisitions), `04-missing-literature.md` acquisitions (V1), `fairgold` toolkit (T2), position-paper hardening (P3), RP-04 O1 corpus assembly, RP-01 clause registries.
- Also legitimate: dossier expansion in `20-GAP-ATLAS/` and `30-IDEAS/` per the OPUS-EXPAND checklists (amendment protocol §4 — append below kernels, never edit them).
- Do NOT: mock up "results" for key-gated studies (evidence discipline §6.3), pre-draft conclusions, or soften anything to make progress possible.

## Playbook C — Fable-tier session (rare; use for judgment only)

- Check the PR queue first — adjudication is the highest-value Fable use.
- Then: any queued Fable-tier gates (transcript reviews, item-sample reviews, external-release recommendations).
- Then: strategic reassessment only if triggered (≥5 gaps changed state, or a bet resolved early).
- Do not spend Fable tokens executing handoff-queue mechanics; delegate down-tier within the session.

## Playbook D — Housekeeping / Sonnet-tier session

- Legitimate: V1 acquisition batches, cross-link additions (V3, new dated files only), formatting/validation runs, dashboard-type rendering.
- Off-limits without an Opus+ session driving: anything touching RP methods, kill criteria, kernels, or external claims.

## What is frozen (all session types)

- Flat docs `../00`–`06` — snapshots; amendments are new dated files.
- Dossier kernel sections; RP-brief kill criteria and pre-registered thresholds; the governance protocol.
- The five bets (B1–B5) — they get *scored*, never reworded.
