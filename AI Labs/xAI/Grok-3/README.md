# Grok-3

## Overview
Frontier foundation model trained on massive compute clusters, featuring deep search capabilities and a specialized reasoning "Think" mode. Trained with 10x more compute than previous models.

## Technical Specifications
- **Release Year:** 2025
- **Version:** 3.0
- **Key Features:**
  - DeepSearch capability for complex research tasks
  - "Think" mode for extended reasoning
  - 10x compute increase over Grok-2
