## Abstract

Novel hybrid models for Kazakh offensive content detection using BERT transformer embeddings with multi-head self-attention and CNN layers. Enables detection of both explicit and implicit hate speech in Kazakh. Kazakh-specific offensive content detection with culturally tailored approach. Combines modern deep learning with language-specific adaptations for the agglutinative Kazakh language.

## Data Description

This is a 2021 literature review surveying techniques for automated detection of offensive language in social media content. It reviews 40 studies across NLP, deep learning, hybrid, and multilingual approaches using traditional ML algorithms (SVM, Naive Bayes, LSTM, CNN). No LLMs are tested and no new dataset is created; it synthesizes existing work on offensive content detection methods and their limitations.
