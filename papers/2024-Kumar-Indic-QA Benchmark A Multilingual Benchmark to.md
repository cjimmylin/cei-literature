# Indic-QA Benchmark: A Multilingual Benchmark to Evaluate Question Answering Capability of LLMs for Indic Languages

## Abstract

Multilingual QA benchmark compiling existing datasets, translated English datasets, and synthetic datasets for Indian languages including extractive and abstractive question answering. QA benchmark covering all four Dravidian languages. Tests comprehension and knowledge retrieval across Indian languages.

## Benchmark

**Name:** Indic-QA

## Data Description

Indic-QA Benchmark: a large multilingual context-grounded QA dataset for 11 major Indian languages covering both extractive and abstractive tasks, compiled from existing datasets, English datasets translated to Indic languages, and a synthetically generated dataset using Gemini.
