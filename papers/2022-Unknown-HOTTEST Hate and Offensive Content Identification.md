## Abstract

Hate and offensive content identification in Tamil using transformer models (BERT, XLM-RoBERTa, IndicBERT, MuRIL) with enhanced stemming for Tamil's morphologically rich nature. Uses HASOC 2021 dataset of YouTube comments in Tamil script. Tamil-specific hate speech benchmark using HASOC shared task data. Tests multiple transformer models on culturally specific offensive content.

## Benchmark

**Name:** HOTTEST / HASOC 2021

## Data Description

The paper evaluates hate and offensive content identification in Tamil using transformer models (BERT, XLM-RoBERTa, IndicBERT, MuRIL) with enhanced stemming for Tamil's morphologically rich nature. It uses the HASOC 2021 dataset of YouTube comments in Tamil script for evaluation. No LLMs (generative models) were tested; only encoder-based transformer models were evaluated.
