# Gemini 2.0

## Overview
Next-generation multimodal model with 10x lower latency and real-time capabilities. Includes "Flash Thinking" for advanced reasoning.

## Technical Specifications
- **Release Year:** 2024 / 2025
- **Version:** Thinking / Flash / Pro
