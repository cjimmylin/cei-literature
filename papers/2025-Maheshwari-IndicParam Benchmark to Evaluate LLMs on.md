# IndicParam: Benchmark to Evaluate LLMs on Low-Resource Indic Languages

## Abstract

Human-curated benchmark of 13K+ MCQs for 11 low and extremely low-resource Indic languages. Top-performing GPT-5 reaches only 45% average accuracy. No model exceeds 58% average score. While not covering the main four Dravidian languages (which are relatively higher-resource), provides methodology for low-resource Indic language evaluation applicable to smaller Dravidian languages.

## Benchmark

**Name:** IndicParam

## Data Description

IndicParam is a human-curated benchmark of 13,000+ MCQs covering 11 low- and extremely low-resource Indic languages (Nepali, Gujarati, Marathi, Odia, Dogri, Maithili, Rajasthani, Sanskrit, Bodo, Santali, Konkani), with each question annotated as knowledge-oriented or purely linguistic. Evaluation scripts at https://github.com/ayushbits/IndicParam.
