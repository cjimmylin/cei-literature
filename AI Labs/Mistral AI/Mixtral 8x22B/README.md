# Mixtral 8x22B

## Overview
Larger MoE model with 141B total parameters, offering significant performance boosts over 8x7B. State-of-the-art open-weight model at release.

## Technical Specifications
- **Release Year:** 2024
- **Version:** 0.1
- **Parameters:** 141B total, 39B active
- **Architecture:** Sparse Mixture of Experts (SMoE)
- **License:** Apache 2.0
- **Format:** Safetensors (BF16)
