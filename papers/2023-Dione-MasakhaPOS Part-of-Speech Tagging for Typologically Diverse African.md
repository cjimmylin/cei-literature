## Abstract

Largest POS dataset for 20 typologically diverse African languages with 1,200-1,500 sentences per language. Uses Universal Dependencies guidelines with native speaker annotation.

## Data Description

MasakhaPOS: the largest POS dataset for 20 typologically diverse African languages, with 1,200-1,500 sentences per language annotated using Universal Dependencies guidelines by native speakers.
