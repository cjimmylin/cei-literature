# I-16 — Deliberation → Artifact Pipelines

**Tier 3** · **Gaps: G-11** · **Programs: RP-08 CONCLAVE** · **Kernel:** Fable 5, 2026-07-07 (FROZEN) · **Body:** Opus draft 2026-07-07

## The idea                        [KERNEL — FROZEN]

Public deliberation now reaches production value documents: a standing lab pipeline feeds elicited public preferences into Model Spec revisions; Democratic ICAI distills deliberation into steering principles; consensus-statement generation carries social-choice guarantees. The gap between "we asked people" and "the model changed" has an engineered bridge — built for opinion distributions, blind to normative traditions.

## Key results

- **The live deliberation→artifact loop** (SEARCH-CONFIRMED, non-arXiv): OpenAI's standing Collective Alignment team feeds public input into actual Model Spec revisions (Aug 2025 onward) — the first production instance of elicited preferences changing a shipped value document.
- **Democratic ICAI** (⚠ 2606.28294 — ⚠ UNCONFIRMED): distills steering principles from preference data via structured deliberation.
- **Fair consensus with guarantees** (2510.14106, Blair & Larson — SEARCH-CONFIRMED): consensus-statement generation on token-level MDPs carrying social-choice guarantees.
- **Antecedents already in vault** (VERIFIED): Collective Constitutional AI (Huang 2024, 2406.07814, IN-VAULT); Moral Graph Elicitation (Klingefjord 2024, 2404.10636, IN-VAULT) — individual-value elicitation, the proof-of-concept these pipelines matured from.
- **Bridging substrate** (⚠ 2604.11224 — ⚠ UNCONFIRMED): quality-sensitive matrix factorization (Community Notes) as a deployed manipulation-resistant cross-factional aggregator.

## Mechanisms & caveats

Every pipeline samples individuals demographically and aggregates *opinions*; it treats pluralism as opinion spread. Deep normative difference — where a Confucian and a Rawlsian disagree about what counts as a reason, not just how to weight answers — is exactly what opinion-pooling flattens. The critical literature names the loss (democratic-ontology deficit, WEIRD-skew, Habermas consensus-telos critique) but supplies no fix. Two of the three headline pipeline citations are ⚠ UNCONFIRMED (2606.28294, 2604.11224); the OpenAI loop is real but documented via blog, not a fetchable paper.
