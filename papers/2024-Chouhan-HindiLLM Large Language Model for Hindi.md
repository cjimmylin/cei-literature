# HindiLLM: Large Language Model for Hindi

## Authors

[[Sanjay Chouhan]], [[Shubha Brata Nath]], [[Aparajita Dutta]]

## Metadata

**Authors:** Sanjay Chouhan, Shubha Brata Nath, Aparajita Dutta

**Year:** 2024

**Type:** preprint

**Venue:** arXiv

## Links

- **arXiv:** https://arxiv.org/abs/2412.20357

## Abstract

Pre-trained autoregressive LLM models (HindiLLM-Small and HindiLLM-Medium) for Hindi. Outperforms existing multilingual models on sentiment analysis, text classification, and NLI. Hindi-specific LLM with associated evaluation benchmarks.

## Benchmark

**Name:** HindiLLM

## Data Description

BBC Hindi news classification dataset used for evaluating Hindi language models, alongside IndicGLUE benchmark tasks and IITP sentiment datasets.
