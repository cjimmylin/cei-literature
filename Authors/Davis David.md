# Davis David

## Biographical Summary

Davis David is an NLP researcher affiliated with Makerere University and the Masakhane community, a grassroots organization dedicated to advancing NLP for African languages. His research focuses on developing NLP resources and tools for low-resource African languages, including sentiment analysis datasets and models. He has contributed to significant efforts in creating benchmark datasets for African language NLP.

## Research Interests

- Natural language processing for African languages
- Sentiment analysis
- Low-resource language processing
- Machine learning for NLP
- Cross-lingual transfer learning
