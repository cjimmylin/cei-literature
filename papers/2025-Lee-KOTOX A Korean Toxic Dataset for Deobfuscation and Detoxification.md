## Abstract

First dataset supporting both deobfuscation and detoxification for Korean. 6.9K neutral-toxic pairs with obfuscated counterparts. 17 transformation rules across 5 linguistic approaches. Three difficulty levels for obfuscated toxic text.

## Data Description

Backfill summary: Models assessed include BERT, GPT-4, Qwen2.5, RoBERTa. Verified dataset/resource link: https://github.com/leeyejin1231/KOTOX.
