## Procedure

### 1. Terminology Standardization

A systematic find-and-replace operation replaced the anthropomorphic term "moral phenotype" with "moral response profile" across the project. The council's philosopher member (Member 10) identified "phenotype" as biologically misleading, implying an underlying "genotype" in the LLM. The replacement was applied to 18 of 24 instances across 9 files. Six instances were intentionally preserved: 5 in the council meta-critique JSON (where members discuss and critique the term) and 1 in a trial JSON (an Atari et al. literature reference using the external authors' terminology). JSON key names were also renamed: `D18_moral_phenotype` became `D18_moral_response_profile` and `claude_moral_phenotype` became `claude_moral_response_profile`.

### 2. Quick Assessment Feature Selection

A 25-feature practical subset was selected from the 169-feature framework using a variance-based discriminative power metric. The procedure was:

1. Load the extended feature matrix (54 benchmarks x 169 features)
2. For each feature, compute variance across all 54 benchmark scores and non-null rate
3. Compute discriminative power = variance x non-null-rate
4. Allocate features proportionally across 7 tiers: A=2, B=2, C=1, D=4, E=6, F=6, G=4 (total=25)
5. Within each tier, select the N features with highest discriminative power
6. Extract 25-column subset scores for all 54 benchmarks
7. Compute Quick Assessment composite (mean of 25 scores) and Pearson correlation with the full-framework composite

The selection script (`scripts/build_quick_assessment.py`) discovered that only 157 of 169 features had actual score data. Five features (B5, B7, B8, B9, C4) were defined in the framework but never operationally scored. The resulting Quick Assessment composite correlated r=0.630 (Spearman rho=0.632) with the full composite — moderate correlation reflecting the subset's emphasis on high-variance features (cultural breadth, citations) versus the full framework's many low-variance LLM-specific features.

### 3. Paper Revision for Meta-Critique Integration

The paper's discussion section (originally 47 lines with a 14-line limitations section) was expanded to address three critical issues identified by the 12-member council meta-critique:

- **Section 5.3.1 (Self-Administration Confound):** Documented that the same model (Claude Opus 4.6) designed the assessment framework and served as test subject for all 23 trials. The MP22 trial's 100% foundation identification accuracy was cited as evidence of instrument awareness. The confound was framed as scope-limiting rather than invalidating.
- **Section 5.3.2 (Statistical Power):** The 54x169 matrix's 0.32:1 subject-to-variable ratio was reported against the Comrey and Lee (1992) minimum of 3:1. Factor analyses were relabeled as "illustrative/exploratory only." The absence of Benjamini-Hochberg FDR correction and confidence intervals was disclosed.
- **Section 5.3.3 (Virtual Expert Council):** All 12 council members being generated by the same LLM was disclosed. The council was reframed as a "structured analytical device" rather than equivalent to independent expert review.

Six additional paper sections were updated: abstract (28→162 features, nine→twelve perspectives), introduction (scope qualifier), methodology (new Section 3.7 "Terminology and Disclosure"), results (self-administration confound qualifier), conclusion (descriptive mapping framing).

### 4. External Paper Ingestion

Twenty-two papers identified in the v2 external search were ingested into the vault. Each paper was created as a Markdown file with YAML frontmatter following the vault's metadata schema. Key allocation proceeded sequentially from EXSR0690 through EXSR0711. Theory-relevant `mp_*` score fields were set to 60 (medium signal) based on the source JSON's `theories` array. Post-ingest validation with `validate_all_papers.py` confirmed all 22 papers passed.

One paper (EXSR0710) had a placeholder URL at ingest time. Subsequent web search identified it as Hendricks, Gil-Buitrago & Pretus (2026), "LLMs Can Fuel Extremist Attitudes Using Universal Moral Framings," published in *Annals of the New York Academy of Sciences* (DOI: 10.1111/nyas.70214). The year was corrected from 2025 to 2026 and the file was renamed.

### 5. Dashboard Deployment

The 10-tab dashboard was deployed to GitHub Pages after verifying that the terminology fix had propagated to all dashboard files. Five static files (index.html, app.js, charts.js, style.css, data.js) were copied to the `cjimmylin/cei-moral-psych-dashboard` repository and pushed to main.

### 6. BibTeX Generation and Citation Resolution

A bibliography file was generated by: (1) extracting all bracket citations from 7 paper sections, (2) cross-referencing against vault paper metadata for DOIs and URLs, (3) reusing entries from the existing Religious Values BibTeX file, (4) manually constructing entries for well-known foundational works. The initial generation produced 126 entries.

Seventeen anonymous citations in the related work section (e.g., "A 2025 study [2025, JMIR]...") were then resolved through targeted web searches. Each was replaced with proper `[Author, Year]` attribution and a corresponding BibTeX entry was appended. The final bibliography contains 144 entries.

### 7. Feature Coverage Documentation

A note was added to the methodology section documenting that 5 of the original 28 features (B5, B7, B8, B9, C4) were not assessed in the 54-benchmark characterization. These features require access to benchmark distribution infrastructure that was not systematically available. The extended 162-feature framework (Tiers D-G) achieved 99.1% coverage.

## Limitations and Decisions

1. **Quick Assessment feature selection was automated** — the variance-based method prioritizes discriminating features, which may not align with theoretical importance. The council recommended expert review of the 25-feature subset.
2. **BibTeX entries for 17 resolved citations** were constructed from web search metadata rather than official publisher exports. DOIs were included where found but some entries may have incomplete page numbers or volume information.
3. **Paper revisions were applied in-place** to living manuscript files, not as new date-prefixed copies. This decision treats paper sections as working drafts, not immutable reports.
4. **The 22 ingested papers** received preliminary `mp_*` scores (60 for relevant theories) based on the source JSON metadata. Full classification pipeline scoring was not run in this session.
