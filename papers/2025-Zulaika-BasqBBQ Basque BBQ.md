## Dataset Information

## Data Description

The study introduces the SOSLM bias dataset, a synthesized collection of 1,638 profane and non-profane sentence pairs created using template sentences with 78 non-offensive identity (NOI) words across six sensitive attributes (gender, race, sexual orientation, religion, disability, social class). The dataset measures Systematic Offensive Stereotyping (SOS) bias in three language models (BERT-base-uncased, RoBERTa-base, ALBERT-base) using the masked language model task, with profane/non-profane word lists generated by GPT-3.
