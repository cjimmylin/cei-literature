# L3Cube-IndicQuest: A Benchmark Question Answering Dataset for Evaluating Knowledge of LLMs in Indic Context

## Authors

[[L3Cube Pune team]]

## Metadata

**Authors:** L3Cube Pune team

**Year:** 2024

**Type:** preprint

**Venue:** arXiv

## Links

- **arXiv:** https://arxiv.org/abs/2409.08706

## Abstract

Gold-standard QA dataset with 4,000 pairs across 20 languages (200 per language) covering five India-specific domains. Language ranking shows Hindi>Marathi>Nepali performance ordering. Covers all four target languages with India-specific QA tasks including cultural knowledge.

## Benchmark

**Name:** IndicQuest

## Data Description

L3Cube-IndicQuest is a gold-standard QA benchmark dataset of 4,000 question-answer pairs (200 per language) covering English and 19 Indic languages across five India-specific knowledge domains, designed to evaluate multilingual LLMs on regionally relevant knowledge.
