## Abstract

Evaluates LLM-as-a-Judge for dialectal toxicity detection. Kurdish among the lower-resource languages where all models struggled, highlighting the performance gap in underrepresented languages.

## Data Description

Multi-dialect toxicity dataset created through synthetic transformations and human-assisted translations covering 10 language clusters and 60 varieties, used to evaluate LLM-as-a-judge consistency.
