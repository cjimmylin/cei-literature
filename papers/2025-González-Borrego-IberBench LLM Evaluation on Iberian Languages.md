## Abstract

Comprehensive benchmark assessing LLM performance on fundamental and industry-relevant NLP tasks in Iberian languages including Spanish varieties (Mexican, Uruguayan, Peruvian, Costa Rican, Cuban). Integrates 101 datasets covering 22 task categories including toxicity detection.

## Data Description

IberBench: 101 datasets across 22 NLP task categories for Iberian languages (Spanish varieties, Portuguese, Catalan, Basque, Galician), standardizing 58 datasets from workshops and benchmarks into a unified evaluation framework with a public leaderboard.


## Notes

**Source:** Language-Organized Benchmark Search (20260213), Agent A9, B2
**Relevance:** Includes toxicity detection and sentiment analysis tasks across multiple Spanish varieties. 23 LLMs evaluated from 100M to 14B parameters.
