## Abstract

Proposes a weakly supervised learning framework for hate speech detection in Thai. Constructs a weakly labeled dataset combining a curated lexicon of Thai toxicity terms with other data sources to address low-resource challenges. Addresses Thai hate speech detection with linguistically enriched approach. Relevant to toxicity evaluation in Thai language.

## Benchmark

**Name:** LIEA-BERT Thai Toxicity Dataset

## Data Description

Proposes LIEA-BERT, a weakly supervised framework for Thai hate speech detection using multilingual BERT fine-tuned with linguistically informed embedding alignment and Proto-MAML on the Wisesight Sentiment Corpus and a Thai toxicity lexicon.
